# PPTe 产品方案摘要（真实项目资料）

来源：docs/PPTe_2.0_完整研发方案_v2.3.md §3、§12、§14.5、§20—22、§41；用户确认的集成原则；2026-09-05 完成度审查。

PPTe 的源文件是语义文档；浏览器渲染、HTML、PDF、PNG 和 PPTX 均由源文档派生。产品需要兼顾人类编辑与宿主 Agent 编辑。主集成方式是 npm CLI 加原生 Skill，MCP stdio 只作可选适配。

GA-A 重点为稳定核心、编辑、保存与恢复、PDF/PNG/Portable 交付。GA-B 增加图表、事实引用、审阅与补丁以及图片型 PPTX。GA-C 增加组件、海报模式和有限语义 PPTX。

内容编辑必须保留非目标格式；组移动必须覆盖全部成员。Agent 修改遵循范围、预览、提交，锁定内容和事实引用应受保护。重排保留内容，重设计应明确受保护元素。保存应区分本地可恢复状态与实际写入项目文件。离线 HTML 是修订副本，需要通过审阅合并回源文件。

审查发现浏览器刷新恢复、文本格式保留、组操作和 Host 审阅入口存在缺口，另需布局工作室与实际宿主验收。本轮实施的结果以测试报告为准。本摘要不预先断言所有验收均已通过，也不把参考字体测量等同于真实字体测量。

验收关注十条真实工作流：资料生成十页、文本编辑、组操作、局部 Agent 改标题、保留内容重排、保护锚点重设计、崩溃恢复、离线副本、修订比较和多格式导出。
