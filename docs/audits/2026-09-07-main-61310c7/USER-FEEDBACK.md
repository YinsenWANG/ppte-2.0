## U01：用轻量审美引导贯穿 HTML 创作

用户观察：整稿风格连贯性不足，背景频繁变色使页面像不同主题拼接。自动化保真通过不等于美观通过，本稿不能登记为人工审美通过。

目的不是为模型套上主题模板，而是激活模型已有的设计判断，并将整稿审美意图落实到实际 HTML/CSS。建议替换 Skill 中现有审美段落，避免叠加提示越写越长：

> 把演示稿作为一件完整的视觉作品来设计。结合内容与受众形成清晰的审美方向，并在编写每页 HTML/CSS 时持续贯彻：重点明确、克制留白、层级清晰、对齐有序，字体、配色和图形语言连贯。页面节奏服务于叙事；背景或风格变化应有内容上的理由，避免为变化而变化，让整稿像同一件作品。发挥你的设计判断，这些是创作提醒，不是模板、固定配色或评分规则。

实施：更新仓库 Skill 源及发布副本来源，检查安装包实际内容。鼓励在作者 CSS 中复用字体、色彩和间距变量，但不强制变量名、设计 JSON、额外规划文件或新增模型调用。封面、章节或强调页可变化；不硬性要求全稿同色，也不规定深浅页配额。审美引导同时关注编辑控件与成稿的职责区别，不把产品 UI 直接当作幻灯片风格。

验收：同一主题新稿按整稿顺序查看，字体、色彩、图形与节奏能被理解为同一视觉语言；由用户反馈判断效果，记录未认可处，不用颜色数量或模板匹配自动宣布美观。保留事实与可读性检查，避免为审美增加昂贵的多轮全稿重生成。

## U02：阅读、编辑、放映三种明确模式，默认阅读

|模式|内容与交互|产品 UI|
|---|---|---|
|阅读（首次打开及保存重开默认）|浏览页面、翻页；文字不可编辑，无对象拖动/选择框；内容原有链接和媒体保持可用|简洁入口：编辑、放映；按需 PDF 可收于次级操作。没有编辑属性面板、插入按钮、空白工具条或未发生编辑时的保存催促|
|编辑（用户明确进入）|选择、输入、插入、布局、撤销/重做、保存能力按实际授权工作|统一顶部工具区；页面导航与上下文属性按需显示；明确退出编辑/阅读和进入放映|
|放映（用户明确进入）|仅当前幻灯片，键盘/触控导航；幻灯片自身媒体控件可按内容设计使用|不显示 PPTe 的浮动菜单、工具条、页码 HUD、编辑框或模式按钮；鼠标移动也不召回这些 UI|

实施：统一状态转换，不让零散 CSS class 各自决定模式。编辑中的文本先提交到内容状态再切换，保留撤销历史和未保存状态；切换不触发下载或丢弃修改。导出清除运行时模式状态，新文件重新打开从阅读进入。Esc 从放映返回进入前的阅读或编辑模式，恢复当前页和编辑上下文。全屏请求失败仍能进入纯净放映；离开浏览器全屏时同步正确恢复，避免界面与状态不一致。打印使用打印布局，不把编辑 UI 混入。

验收：首次直开、下载重开默认阅读；阅读→编辑→放映→Esc，以及阅读→放映→Esc 两条路径均通过。覆盖有未保存编辑、媒体聚焦、全屏被拒和浏览器退出全屏。阅读与放映的 contenteditable/选区/事件行为都检查，不能仅隐藏边框冒充禁止编辑。

## U03：统一插入入口，完成可用的对象操作

编辑模式提供一个清晰的“插入”菜单，至少含文本框、形状、图片、表格。形状子菜单先支持矩形、圆形/椭圆与线条等基础能力；图片打开本地选择器；表格提供轻量行列选择。已有视频等能力可放在同一入口的次级项，不再平铺大量低频按钮。不要保留无动作按钮、占位菜单、重复入口或仅展示技术参数的选项。

工具区保持稳定视觉：统一图标体系、文字、间距、圆角、焦点与禁用状态；图标含可访问名称，撤销/重做使用可辨识的标准方向。属性区随选择对象显示：文本的字号/粗体等，形状的填充/边框，图片的替换/裁切，表格的行列与单元格格式。未选中对象时不展示一堆无法使用的控件；需禁用时说明原因。不要重写操作系统文件选择器。

实现落点：主要检查 html-editor 的 workspace.ts、commands.ts 与模式/选择逻辑，沿用共享命令、唯一标识、保护范围、历史和保存管线。新增对象必须进入当前页正确内容容器，初始位置可见、可选、可移动/布局；不能直接追加到外层 section 导致标题遮住图片，也不能将所有作者节点强制改为绝对定位。文本框可输入；形状可调大小、填充和边框；图片可裁切/替换；表格可编辑内容与增删行列。对象新增/修改/删除支持撤销重做与保存重开，处理锁定对象时不误伤无关操作。

验收：用真实 12 页稿分别插入四类对象并完成一次修改、撤销、重做、下载和新进程重开；检查阅读、放映和按需 PDF 的内容一致性。实际鼠标与键盘测试菜单、焦点、关闭、滚动和窄窗口，验证菜单不被画布覆盖、也不遮住添加页。不能只调用内部命令证明 UI 可用。此项与 N01–N03 联合修复，避免出现另一套插入管线。

## U04：彻底移除放映悬浮菜单

移除放映中的产品操作菜单及其鼠标移动/悬停召回逻辑，不只是降低透明度、延迟隐藏或缩成图标。上一页/下一页使用方向键、PageUp/PageDown、空格等既有快捷键，触控提供无可见菜单的翻页手势；导航不能抢夺视频操作、链接点击或文本输入焦点。Esc 退出，浏览器自身的安全提示不由产品控制。

操作提示可在进入放映之前按需提供一次，不能做成放映后覆盖内容的浮层。保留黑屏等现有快捷键能力；讲稿本身的交互内容不等同于应删除的 PPTe 菜单。

验收：进入放映后移动鼠标、停留、点击空白、翻页、黑屏恢复，全程无 PPTe 浮动菜单；能通过键盘和触控翻页并正常退出。在不同页面背景下检查无残留边框、阴影或透明点击拦截层。
