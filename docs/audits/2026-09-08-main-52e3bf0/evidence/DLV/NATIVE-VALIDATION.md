3. 再改文字并完成另一裁切，不点击保存，等待自动保存确认，记录新摘要和正文。退出整个浏览器进程，重新打开同一路径，确认两轮文字、裁切、原图仍在，默认阅读；不得用下载文件替代同一路径重开。
4. 另开副本分别测试：取消选择器、拒绝/撤销权限、选择同名不同内容文件、关联后从外部编辑目标造成冲突。确认未静默覆盖、未自动下载或循环授权，已提交裁切/文字仍保留；一次撤销恢复裁切前状态。真实失败与保存中继续输入可复现时记录重试和新修订排队；无真实复现条件的子项单独 pending，不能用注入通过替代。
5. 有变化的裁切分别尝试阅读、放映、换页、选另一对象、删除和替换；三个出口“应用并继续/放弃并继续/留在当前”分别检查。Esc 恢复进入裁切前状态，无变化直接完成不应新增撤销。关闭前未完成提示按浏览器允许范围记录。
