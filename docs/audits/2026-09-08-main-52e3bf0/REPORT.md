## 可执行修复合同

- 顶栏分为稳定的标题区域、模式切换区、通用动作区；保存动作和状态使用独立保留槽位。建议保存区放标题附近，通用模式/PDF/放映按右侧固定锚点布局，避免编辑状态在其右侧增减节点宽度。
- 阅读态隐藏保存内容但保持布局槽位，不让隐藏元素获得焦点或被辅助技术朗读；不能单用 opacity:0 制造透明可点按钮。
- 保存区域宽度不依赖“未改动/保存中/已保存/失败/冲突”等文案，短状态截断，完整说明在面板内；不因错误自动展开使顶栏增高或重排。
- 窄屏使用明确行列及 minmax(0,...)，主按钮不拉伸抢占邻列；下载兜底较长标签需在同样有界的槽位内合理布局，不能被截断到无法理解。
- 固定的是交互位置，不是画布：阅读切编辑增加工具条造成画布变化可合理存在，不能通过冻结整页影响画布适配。
- 测试1440/1024/390，同一视口下阅读→编辑→修改→保存中→成功/失败/冲突→返回阅读；支持写回与下载兜底分别测。公共按钮x/y及尺寸变化不超过1 CSS px（测试目标），无重叠、水平溢出、焦点丢失。断言真实边界框，不只检查CSS类或截图存在。
