# PPTe v2.3 前两周开发启动清单

## 唯一垂直切片

```text
打开最小 Document
→ 渲染 Text/Image/Shape
→ 拖动 Image（Transient）
→ IME 安全文字编辑
→ Agent text.replaceContent
→ Scope + Change Contract 阻止越界
→ Preview / Diff / Commit
→ Undo
→ Append Recovery Journal
→ Atomic .ppte Checkpoint
→ 重开一致
```

- Text/Image/Shape Renderer。
- 最小合法示例和 Contract Deck。

## Week 2

- `element.move`、`text.replaceContent`、Inverse/Undo。
- Mutation Budget 与 Invariant。
- Selection Overlay、Drag Transient、IME Local State。
- Journal Append、Checkpoint、Reopen。
- Agent Mock 与 E2E。

- Portable 完整编辑器。
