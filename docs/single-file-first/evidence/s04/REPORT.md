## Measured changes and recovery boundary

For 30 inputs, baseline → final: notifications 60 → 30; canonical serializations 60 → 11; synchronous storage writes 60 → 11; thumbnail slide clones 360 → 30. Across input/turn/save run: clones 840 → 40. ID lookup now drains pending DOM mutation records before lookup, including same-stack replacement, rename, insertion and history changes; tests assert stale nodes cannot be returned. Typing preserves contextual controls. Structural changes rebuild thumbnails; nonstructural commands update only affected slides, page navigation updates current markers without cloning. Visible-first idle thumbnail scheduling is not implemented and remains a potential next optimization.

Drafts retain immediate first-edit persistence and coalesce subsequent typing checkpoints to 200 ms. **A crash can lose edits since the last checkpoint: nominally up to 200 ms plus event-loop blocking/timer throttling, not a hard real-time bound.** This replaces baseline every-key persistence intentionally. Before-unload/pagehide/visibility-hidden attempt a final checkpoint; before-unload still warns about unsaved changes. These hooks cannot guarantee persistence on process kill or physical power loss. IME is committed as one command; file save remains 800 ms debounced and serial. Failed storage remains visibly unavailable. This implementation still uses synchronous localStorage at checkpoints; asynchronous recovery storage is not claimed. Revision cache contains only one content string per controller; newer edits invalidate it, while draft and file write for the same revision reuse it.

Repeated-media benchmark (40 references, six packaging invocations): baseline 40 Base64 calls per invocation → cold 1 / hot 0. Raw traces retain actual times, hits/misses, reads, authorization count and cache size. Single-file serialized resources are still duplicated data URLs as before; byte-deduplicated embedded resource tables and media undo capacity/lifetime belong to S06 and are not claimed by this encoding optimization.
