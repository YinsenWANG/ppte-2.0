09 / 退休边界现有证据不足以判定退休

可达 ≠ 执行；不可达 ≠ 已退休。

不能按名字退休

importer-legacy 为 6 条边；“legacy”只是名称，不能证明已停用。

不能按低边数退休

compatibility 为 4 条边；边数小不说明消费者已迁移。

不能按可达集退休

CLI 可达集不等于全项目入口集合，也不是打包后执行图。

设计目标 退休证据链

补齐入口与消费者清单 → 核对静态路径与类型依赖 → 验证替代行为 → 明确移除范围与回退方案。
