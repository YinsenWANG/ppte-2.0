<div class="top"><span>01 / PRODUCT</span><span>产品定位</span></div>
<div class="kicker">一个桌面客户端，多种模型来源</div>
<h2>把云端、Web 与本地模型<br>放进同一个工作入口。</h2>
<p class="lead">Cherry Studio 支持多个 LLM 提供商，并提供 Windows、Mac、Linux 桌面版本。</p>
<div class="grid three">
<article class="card"><span class="num">CLOUD / 云端服务</span><h3>连接主流 LLM</h3><p>OpenAI<br>Gemini<br>Anthropic 等</p></article>

<article class="card"><span class="num">LOCAL / 本地模型</span><h3>接入本地运行环境</h3><p>Ollama<br>LM Studio</p></article>
</div>
<p class="small muted">README 列出的产品体验：开箱即用，无需环境配置；支持浅色／深色主题与透明窗口。</p>

<div class="top"><span>05 / CONTRIBUTING</span><span>七类贡献方式</span></div>
<div class="kicker">找到适合你的入口</div>
<h2>贡献可以从代码开始，<br>也可以从一次解释开始。</h2>
<div class="grid three">
<article class="card"><span class="num">BUILD</span><h3>开发与修复</h3><p class="muted">① 贡献代码：开发新功能或优化现有代码。<br>② 修复 Bug：提交发现的问题修复。</p></article>
<article class="card"><span class="num">SHAPE</span><h3>维护与设计</h3><p class="muted">③ 维护 Issues：协助管理问题。<br>④ 产品设计：参与设计讨论。</p></article>
<article class="card"><span class="num">CONNECT</span><h3>文档与社区</h3><p class="muted">⑤ 编写文档：完善手册与指南。<br>⑥ 社区参与：讨论并帮助用户。<br>⑦ 推广使用：让更多人了解项目。</p></article>
</div>
<p class="rule lead">选择一个你理解的问题，把改进的内容和理由讲清楚。</p>

<div class="top"><span>06 / FIRST PULL REQUEST</span><span>从入口到提交</span></div>
<div class="kicker">你的第一个 PR</div>
<h2>先理解贡献约定，再提交改变。</h2>
<p class="lead">探索仓库，选择一个 <strong>good first issue</strong>，或提出自己的改进建议。</p>
<div class="flow">
<article class="step"><div class="big">01</div><h3>Fork 与克隆</h3><p>Fork 仓库，并克隆到本地。</p></article>
<article class="step"><div class="big">02</div><h3>创建分支</h3><p>为你的修改建立分支。</p></article>
<article class="step"><div class="big">03</div><h3>提交更改</h3><p>Commit 并推送你的修改。</p></article>
<article class="step"><div class="big">04</div><h3>发起 Pull Request</h3><p>描述修改内容，以及做出修改的原因。</p></article>
</div>

<div class="top"><span>07 / CO-CREATION</span><span>开发者共创计划</span></div>
<h2>让持续贡献，获得持续支持。</h2>
<div class="split">
<div class="stacked">
<div class="big green">&gt; 30</div>
<h3>有意义的 commits</h3>
<p class="muted">在任一统计周期内，对 Cherry Studio 的任一 GitHub 开源项目贡献超过 30 个有意义的 commits，即符合 README 所述奖励资格。</p>
<p class="small pink">门槛为“超过 30”，不是“达到 30”；统计对象为 commits，并非 PR 数量。</p>
</div>
<div class="stacked">
<article class="card"><h3>Cursor 订阅支持 <span class="green">US$70</span></h3><p class="muted">提供 70 美元额度或订阅费用报销。</p></article>
<article class="card"><h3>DeepSeek 与 Qwen</h3><p class="muted">README 所述权益：无限量模型 API 调用。</p></article>
<article class="card"><h3>不定期前沿技术福利</h3><p class="muted">包括 Claude、Gemini、OpenAI 等模型的 API 访问机会。</p></article>
</div>
</div>
<div class="note">README 所述首期统计周期为 2025 年第三季度（7—9 月），奖励安排在 10 月 1 日发放。此处复述原文计划，不表示奖励已发放，也未核验当前执行情况。</div>
