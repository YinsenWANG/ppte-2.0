共创 / README 所述激励计划

以有意义的贡献，
支持开发者共同成长。

统计周期内的资格条件
> 30

次有意义的提交

开发者在任一统计周期内，向 Cherry Studio 的任一 GitHub 开源项目贡献超过 30 次有意义的提交，可获得材料所述权益。

门槛是“超过 30 次有意义的提交”，不是 30 次 PR。

70 美元 · Cursor 订阅支持

为 Cursor 订阅提供额度或报销。

DeepSeek 与 Qwen · 无限 API 调用

作为 README 所述贡献者权益提供。

不定期 · 前沿模型访问福利

例如 Claude、Gemini、OpenAI 等模型的 API 访问。

材料中的首期安排：2025 年第三季度（7—9 月）为首个统计周期，奖励计划于 10 月 1 日发放。

上述日期与权益为固定 README 的计划描述，不代表已核验发放情况或当前兑现状态。未来持续完善福利也属于计划。

边界 / 社区版与企业版

社区版开放贡献，
企业版面向团队集中管理。

企业版基于社区版，定位为可私有部署的 AI 生产力与管理平台。

比较维度社区版企业版
开源范围开源部分向客户开放
许可 / 费用AGPL-3.0 许可买断 / 订阅收费
管理后台README 对比表标为“—”集中模型接入、员工管理、共享知识库、访问控制、数据备份
服务端部署README 对比表标为“—”专属私有部署：本地服务器或私有云
企业能力重点桌面客户端与开源协作统一管理云端及私有模型、角色权限、团队知识与备份恢复
许可边界：README 说明社区版允许商业使用，前提是完整遵守 AGPL-3.0。若需豁免 AGPL-3.0 要求的商业许可，可联系 bd@cherry-ai.com。企业版与商业许可豁免应分别了解。
