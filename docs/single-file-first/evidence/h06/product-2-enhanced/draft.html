07 / 可信保存与重开可靠性设计目标

“已保存”，必须由文件来证明。

写入有顺序

串行队列绑定 saveRevision。中文输入法组合期间不提交半个汉字；旧请求不能覆盖新版本。

冲突不覆盖

先检查文件摘要／版本。外部修改时停止写入，提供重新读取和保留当前修改的恢复分支。

重开可验证

关掉页面，从原路径重开核对。草稿只在匹配基准上恢复；失败保留修改，并持续显示原因。

无授权、仅草稿、冲突与失败须明确显示。缓存不是原文件，关闭警告也不能代替及时保存。

断网、崩溃、只读、磁盘满与外部改动均需实际验证08 / 12
08 / 放映与静态输出放映 / PDF 设计目标

观众只看见你的内容。

让观点
占据整个画面。放映画面示意 · 编辑工具不进入观众视图

放映模式

只显示当前幻灯片。控制按需唤出、闲置隐藏；黑屏为真实黑幕，退出与恢复可由键盘完成。备注、预览和计时进入专用视图。

PDF 按需导出

一张幻灯片一页，所有步骤静态可见，视频使用封面。优先浏览器打印，尽可能保留文字与链接；检查分页、裁切、字体和透明度。

HTML 为唯一默认成品；不自动生成 PDF，不提供 PPTX / PPT / ODP / Keynote 新产品入口。

媒体默认内嵌；大视频的单文件成本需先说明，再由用户选择09 / 12
09 / 单文件的内部约定封装与安全设计目标

只存一份内容，编辑后仍是同一作品。

最终 HTML 的设计载荷

页面 HTML/CSS
＋ 内嵌资源
＋ 轻量元数据
＋ 可信编辑 / 放映运行时

不再嵌入完整 .ppte ZIP、Base64 项目副本与另一份渲染文档。

隔离

持久内容建议放在 inert template；挂载到隔离 iframe，保留 CSS 能力，禁止作者内容任意脚本与默认外部请求。

序列化

保存从活动 DOM 序列化一次，清除选区、拖拽柄与工具 UI；反复保存不能累积模板和运行时副本。

保护

本地服务仅绑定 loopback 与授权文件范围；文稿 iframe 不持有保存令牌。被拒绝的可执行内容必须明确报告。
