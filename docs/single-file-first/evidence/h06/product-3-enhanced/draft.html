保存是写回文件，

方案中的入口如何写回原文件自动保存边界
NPM 本地编辑入口
固定方案推荐路径		绑定用户选择的 HTML，
校验冲突后写回同一路径。		目标默认开启，输入停顿约 800 ms 后保存；成功后显示落盘状态。

TRUST / 以重开验证保存设计目标

关掉，再从原路径打开。
修改还在，才算数。

已保存有修改保存中写入确认 → 已保存

状态真实

无授权、仅草稿、冲突、失败分别表达。写入缓存或刚发起请求，都不能显示“已保存”。

冲突不覆盖

外部 Agent 或另一窗口改动时停止写入，提供重新读取与保留当前修改的恢复分支。

失败可恢复

保存失败保留修改，状态持续可见；Cmd / Ctrl + S 可重试。草稿恢复需匹配文件基准。

目标验证：断网、崩溃、只读、磁盘满、权限丢失与外部修改。断电耐久性必须由实际测试确认。

串行版本写入；中文输入组合期间不提交半个汉字。浏览器与外部进程的并发边界需明确。08 / 12

SCOPE / 轻量与可信设计目标

一个文件，不等于重复打包一切。

只保留一份持久内容

页面 HTML/CSS、内嵌资源、轻量元数据与可信编辑／放映运行时。

不再嵌入完整项目 ZIP、Base64 项目副本和另一份渲染文档；反复保存不累积旧版本载荷。

内容与编辑器隔离

保留 Grid / Flex、渐变、SVG 与字体表现；作者内容默认不能执行任意脚本。

通过 CSP 与 iframe 权限验证网络、导航等边界；被拒绝的可执行内容需明确报告。

保留

资料理解、来源标注、NPM 与原生 Skill；适用的 DOM 交互经验。

退出新默认路径

旧 IR 与固定 Recipe、.ppte 交付；移除 PPTX / Office 依赖与验收。

尊重旧作品

不删除已生成文件，不强制覆盖旧 HTML；旧版保留，迁移按需。

默认系统中文字体，不下载完整字体；QuickJS、Electron、多人协作不是本阶段依赖。10 / 12
EVIDENCE / 不用口号代替实测设计目标 · 初始门槛待实测冻结

更快、更轻、更好看。
每个判断都要有证据。

热环境总耗时中位数
≤ 1.25×

相对直接 HTML 基线；token 总量中位数目标 ≤ 1.20×。尾部与失败单列。

十二页轻资源稿纯增强
≤ 2 秒

不含模型、研究与浏览器渲染。完整 HTML 目标 ≤ 1 MB，不含媒体与可选字体。

首轮九对盲评
≥ 6 对

不逊于直接 HTML；由负责人和两名目标使用者评估，且无人认为 UI 阻碍基本使用。

同条件比较

同模型、推理配置、材料、页数与资源。三类材料各三对，保留全部首稿与失败；冷启动与日常生成分开记录。

独立失败不能被平均掉

丢事实、文字遮挡、保存丢失均单独判失败。目前没有受控数据支持“必然慢数十倍”。

运行时目标 ≤ 250 KB gzip；同步报告原始、gzip 与媒体字节。以上均非实测成绩。11 / 12
