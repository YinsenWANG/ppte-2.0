<h2 data-ppte-id="ppte-198">一个文件，不等于零授权写盘。</h2>
<p class="lead muted" data-ppte-id="ppte-199">单个 file:// HTML 无法在任意浏览器里，无授权地改写自身磁盘文件。</p>
<table data-ppte-id="ppte-200"><thead data-ppte-id="ppte-201"><tr data-ppte-id="ppte-202"><th data-ppte-id="ppte-203">固定方案入口</th><th data-ppte-id="ppte-204">原文件保存的设计目标</th><th data-ppte-id="ppte-205">自动保存边界</th></tr></thead><tbody data-ppte-id="ppte-206"><tr data-ppte-id="ppte-207"><td data-ppte-id="ppte-208">NPM 本地编辑入口</td><td data-ppte-id="ppte-209">轻量服务绑定所选 HTML，检查冲突后写回同一路径</td><td data-ppte-id="ppte-210">目标为停顿约 800 ms 后保存；成功后显示落盘状态</td></tr><tr data-ppte-id="ppte-211"><td data-ppte-id="ppte-212">浏览器支持且已授权</td><td data-ppte-id="ppte-213">首次选择 / 绑定目标文件，后续通过文件写入 API 保存</td><td data-ppte-id="ppte-214">授权有效时自动保存；重开检查权限，必要时重新授权</td></tr><tr data-ppte-id="ppte-215"><td data-ppte-id="ppte-216">缺少写入 API / 权限</td><td data-ppte-id="ppte-217">明确无法直接覆盖；提供本地入口或显式下载保存</td><td data-ppte-id="ppte-218">仅显示草稿 / 尚未写入文件，不能承诺原文件自动更新</td></tr></tbody></table>
