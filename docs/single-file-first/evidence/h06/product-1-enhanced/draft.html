05 / 日常修改设计目标 · 能力逐项验收

改内容，也尊重原来的布局。

先打通主体验

改标题 · 换图片

编辑、自动写回、重开保留，构成首轮可体验交付的核心。

文字选区格式、表格行列、常用图形属性与媒体能力，仍需在后续阶段逐项完成。

自由布局，不被拖坏

绝对定位对象可拖动、缩放与旋转；Grid/Flex 调整重排、间距与容器。

局部修改，保留人工工作

统一撤销栈；AI 默认只改选定节点或页面，以基准摘要避免覆盖新修改。

复杂 SVG 默认整体处理，可解锁深入编辑。不承诺所有外部网页 CSS 都能由通用控件无损修改。

06 / 可信保存设计目标

“已保存”，必须意味着写入了文件。

缓存是恢复草稿。下载发起，也不是原文件已更新的证据。

已保存→有修改→保存中→写入确认后：已保存

无授权 / 仅草稿

明确提示尚未写入文件，不把浏览器缓存包装成落盘。

外部修改 / 冲突

停止覆盖，提供重新读取与保留当前修改的恢复分支。

写入失败

保留修改与可见状态；Cmd/Ctrl+S 可重试。

依据：固定方案 §5 · 串行版本写入；中文输入组合期间不提交半个汉字07 / 12
07 / 保存与重开固定方案支持矩阵 · 待实测合同

一个文件，不等于零授权写盘。

单个 file:// HTML 无法在任意浏览器里，无授权地改写自身磁盘文件。

固定方案入口原文件保存的设计目标自动保存边界
NPM 本地编辑入口轻量服务绑定所选 HTML，检查冲突后写回同一路径目标为停顿约 800 ms 后保存；成功后显示落盘状态
浏览器支持且已授权首次选择 / 绑定目标文件，后续通过文件写入 API 保存授权有效时自动保存；重开检查权限，必要时重新授权
缺少写入 API / 权限明确无法直接覆盖；提供本地入口或显式下载保存仅显示草稿 / 尚未写入文件，不能承诺原文件自动更新

验收动作：修改 → 写入确认 → 关闭 → 从原路径重开 → 内容仍在。

依据：固定方案 §5.1–5.3 · 此页描述该方案的目标，不宣称当前 CLI 已支持08 / 12
08 / 放映与输出设计目标

观众只看内容，作者保留控制。

放映画面示意

让表达
占满舞台。

只显示当前幻灯片，编辑工具退出观众画面。

控制按需出现

唤出、悬停或键盘聚焦时显示；闲置后隐藏。备注、预览和计时放入专用视图。

黑幕与退出可预期

黑屏是真实黑幕；键盘可以退出并恢复到正确编辑位置。

PDF，按需静态交付

更多 → 导出 PDF。一页对应一张幻灯片；步骤静态可见，视频使用封面，编辑器与控制条不进入打印。检查分页、裁切、字体和透明度。

依据：固定方案 §3、§6、§9 · 优先浏览器打印，尽可能保留文字与链接09 / 12
09 / 轻量且可信设计目标

一份内容，一套运行时。

单 HTML

页面 HTML/CSS + 内嵌资源
轻量元数据 + 可信编辑 / 放映运行时

↓

隔离的作品画布

保留 Grid / Flex / SVG 与字体能力
作者内容默认不能执行任意脚本

保存不积累副本

从活动 DOM 序列化一次，清除选区、拖拽柄与临时工具 UI；不重复嵌入旧模板和项目包。

轻资源，少依赖

默认使用系统中文字体与轻量 SVG；不下载完整字体，不让简单文本生成依赖浏览器安装。

资源默认内嵌并限制外部请求。被拒绝的可执行内容要明确报告，不能静默破坏版式后宣称成功。

依据：固定方案 §4.2、§7 · 具体封装须先通过保真与体积原型10 / 12

十二页轻资源纯增强目标

不含模型、研究与浏览器渲染

体积也要透明

无媒体 runtime 目标 ≤ 250 KB gzip；不含用户媒体和可选字体的完整 HTML 目标 ≤ 1 MB。同时报告原始、gzip 与媒体字节。

盲评不替代可靠性

三类材料各三对；负责人和两名目标用户盲评。首轮九对至少六对不逊于直接 HTML。丢事实、遮挡、保存丢失均为独立失败。
