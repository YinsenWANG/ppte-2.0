# F03 图片完整操作

状态：implemented-pending-validation。实现与自动化证据见 verification/result.json；原生桌面和人工验收仍 pending。本任务不改变 PDF 架构或 F04A/F04 状态。

## 实现

- 解码得到真实宽高，初始图片框按原图比例适配 320×240 上限。小图通常不放大，极小图给予可选择尺寸；放置算法还可等比缩小以避开文字/媒体。保留原始字节，不把裁切或尺寸修改重新编码为图片。
- 沿用 R2 的作者容器放置、绝对定位拖动、Alt+方向键、流式顺序/对齐，以及尺寸手柄。Grid/Flex/普通流不伪装成自由定位，不改变整页定位合同。没有可用空白时回滚插入并给出明确错误；不能据有限夹具宣称任意 CSS 布局均可编辑。
- 插入和替换图片显示读取状态，可取消。读取过程中阻止重复插入；离开编辑/切页取消本次读取。FileReader 和解码阶段均检查取消；取消不产生 DOM、dirty 或撤销事务。临时解码 Image 释放 src；不声称可观测 GPU 缓存释放字节。
- 图片替换选择器与插入统一接受 PNG/JPEG/WebP/GIF/AVIF；视频仍限 MP4/WebM。捕获目标和文件后清空选择器，失败后允许再次选同一文件；格式/读取/解码/超 16 MiB 错误保留原稿。
- 非破坏裁切、焦点、完整显示/重置、替换后的完整显示与说明清空继续使用原有事务。图片拖动/缩放取消手势清理临时状态。保存沿用 F02 队列与 S06 资源去重/按需挂载，重复原图在下载文件只嵌入一份。
- 未新增依赖。未移除额外产品能力；正文、形状、表格、SVG、视频和历史数据的保留合同不变。B2 安全链接仍是其他任务需闭环的审查项，本任务不将其标为解决。
