# F05 · 整体 UI 细节打磨

F05 的独立 UI 实现与自动化验收完成；任务整体为 `implemented-pending-validation`。F04 依赖未满足，PDF 仍不可用；目标设备与用户人工确认待验。本轮没有 PDF 实现或架构变更。

## 改动与边界

- 沿用认可原型的白/冷灰工作台、蓝紫焦点、紧凑分组、18px 本地线条图标及上下文属性。统一撤销/重做图标与按钮尺寸，各区域禁用状态采用同一背景、文字和光标，disabled 不再响应 hover 高亮。
- 阅读缩略图移除隐藏页面操作菜单留下的空栏。390px 顶栏改成三列，标题、保存状态和模式/放映/PDF 各有位置，PDF 文案使用正常字号；保持 44px 窄屏命中区。
- 页面导航的两处入口同步 `aria-expanded` 和 `aria-controls`，首尾翻页正确禁用；属性标题/关闭按钮在桌面滚动时也保持可达。
- 保存面板下载动作恢复完整可见名称“下载更新后的文件”，避免把明确的恢复选择藏在单个图标中。
- PDF 保留一级禁用入口，说明改为“现有路线未通过视觉与文字保真验证”，与 F04A 结论③一致。

样式均位于作者 iframe 外，不修改作者 HTML/CSS。未增加依赖、服务、外部字体、菜单或输出格式。页面移动/新增保持可用并补充 40 页真实 UI 自动化操作；本轮额外产品能力移除：**无**。保存恢复/保护/布局等建议删减未被当作用户已确认删除。

## 证据与复验

- `Cherry-F05.ppte.html`：由审查原始 10 页 Cherry 稿增强，离线打开默认阅读；不覆盖历史交付稿。
- `screenshots/`：同稿 read/edit/save 的 1440/1024/390 截图及 40 页长稿 1440/390 截图。
- `journeys/controls.json`、`responsive.json`、`long.json`：浏览器版本、几何数据与断言结论。
- `verification/result.json`：四层状态、命令、日志、平台、时间与实现提交；完整日志一并保留。
- `HUMAN-VALIDATION.md`：待执行的原生与人工清单。

开发期第一次自动化失败被保留在 `verification/initial-focused.log`。保存面板 `details` 的 toggle/定位异步，测试现等待真实 `aria-expanded=true` 后再测量。第二次日志与 `screenshot-side-effect.json` 保留撤销冲突：Playwright 默认隐藏光标在 contenteditable 留下空 style 属性，污染了截图后的文稿。改用 `caret:'initial'`，并新增截图前后正文严格一致断言；未改产品历史冲突校验、未弱化/移除断言。首次全仓绿色日志存放 `verification/first-green/`；补全下载文字和截图不变性断言后重新运行全部门禁。
