# F06 原生与人工验收：pending

当前可执行的是已安装 Chrome 的 headless、file://、offline 自动化。本轮工具发现未找到桌面/浏览器原生操作工具，也没有远程目标设备执行者或回执。自动化文件选择器、下载到磁盘和全新浏览器进程不等于物理系统文件授权与原文件写回。

目标机使用同一个 `Cherry-F06.ppte.html` 副本，不需服务或 Node。记录 OS/浏览器完整版本、时间、录像或步骤截图、选择前后文件 SHA256、实际正文与保存修订及 UI 状态。以下每项均 pending，不能用本轮自动化结果代填。
