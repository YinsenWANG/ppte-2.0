## 实现与边界

- 保存按钮与 Ctrl/Cmd+S 在不支持写回、取消、拒绝授权、权限失效时均不触发下载。保存面板解释原因，只有用户点击“下载更新后的文件”才下载；编辑、dirty 和确认修订保留。
- 选择/读取异常归为 failed，取消/拒绝归为 unauthorized；异常不被后续输入或草稿配额失败冲掉。自动定时器不能在错误后私自重试；手动重试仍可用。已授权句柄先 queryPermission，失效才重新请求。
- 保留单写入队列、内容/身份/保存修订/历史基线验证、写前双重 hash 检查、close 后回读确认、写入失败不改变成功基线。写入期间继续编辑仍显示 saving；旧确认不能清掉新改动，手动请求可排队。
- IME 组合期间不发起文件选择/保存/下载；延续完整事务、撤销与拖动的原有命令记录。系统 IME 没有实机验收。
- Enter 使用宿主内原生 insertLineBreak，Shift+Enter 保持原生路径；不放宽混合容器判定。粘贴处理文字和换行，剪贴板 HTML 布局/样式不导入；原稿现有内联格式、对象结构不改写。浏览器 execCommand 是已有编辑技术的延续，Chrome 已测，其他浏览器仍待验。
- 草稿按修订和基线复用序列化及存储结果，减少重复同步写入。保留首个修改立即检查点、持续输入至多约 200ms 检查点窗口（另加主线程调度延迟）；仍使用 localStorage，未宣称异步存储或大型文稿性能闭环。
