DESIGN PROPOSAL01 / 12

作品，就是 HTML

PPTe HTML-first

以下均为设计目标；本稿是原始 HTML，不含真实编辑器或保存服务。
01 / DELIVERY02 / 12

只交付一个作品

演示稿.html

阅读、编辑源和放映入口统一；PDF 由用户明确请求后产生。
02 / AUTHORING03 / 12

直接设计页面

HTML + CSS + SVG

模型掌握构图、字级、渐变与节奏。工具负责增强与检查。
03 / STRUCTURE04 / 12

让浏览器负责布局

Grid / Flex / 原生 table

不再以另一份完整数据镜像定义页面。DOM 与 CSS 是作品表示。
04 / EDITING05 / 12

需要的时候才出现工具

选择 → 上下文工具 → 局部修改

统一顶栏、缩略图与浮动工具栏，避免常驻属性表单挤占作品。
05 / SAVING06 / 12

保存要落在原文件

修改 → 保存中 → 写入确认

只有磁盘写入成功才能说“已保存”。缓存草稿必须单独标识。
06 / LOCAL07 / 12

推荐入口：本地编辑

ppte edit ./作品.html

设计中的本地服务绑定用户选定文件，提供跨浏览器的原文件保存路径。此命令尚未在新产品中实现。
07 / PERMISSION08 / 12

直开文件，也有能力边界

授权有效，才可直接写入

没有写入 API 或授权时，明确提示本地入口或显式下载；不能承诺自动覆盖。
08 / RECOVERY09 / 12

冲突不能悄悄覆盖

摘要检查 · 串行写入 · 恢复版本

外部修改和另一窗口写入都必须触发冲突处理。这些可靠性承诺仍需实测。
09 / PRESENT10 / 12

把画面留给观众

当前页面，全心表达

闲置控件隐藏、真实黑屏、键盘退出；演讲者信息进入专用视图。
10 / FIRST MILE11 / 12

先跑通最短完整体验

生成 → 编辑 → 自动保存 → 重开 → 放映

在纵向体验通过之前，不扩充高级表格、动画或插件。
