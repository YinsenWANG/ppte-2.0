# C05 — Host / Portable presentation contract

Implementation: `edaa15d647385184b51ca58ef05818ad44e06310`. Baseline: `a822a1e790280f0b40a8be8ccc393ead233e7eda`.

The shared PresentationController now owns fullscreen request epochs and ownership. Both shells use it, defer presentation during composition, cancel pending entry on exit, reject content commands while presenting, and preserve failed drafts. Host preserves its rendered markup across status updates and applies animation visibility before paint. Portable no longer advances on arbitrary canvas/media clicks. Previous-step navigation includes same-page zero and the previous page's final step. Host presentation fits both viewport dimensions.
