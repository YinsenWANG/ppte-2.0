# F05 — animation configuration and step playback

Implementation evidence: `tests/animation-step-contract.test.ts` (Node test runner,
including real offline Chromium Host and Portable journeys).

| Criterion | Concrete evidence |
| --- | --- |
| Independent step/slide commands, stable slide identity | Sparse 0→3→next-page steps; reverse 3→0→previous-page-last-step; next/previousSlide reset to zero; first/last boundaries; explicit goto; reordered slide IDs. Runtime holds slideId in transient state, index is derived; legacy index-only helper calls remain compatible. Both browser entry points exercise independent keyboard navigation. |
| Declared effects/timing/directions execute; other fields retained/reported | Browser animation keyframes and timing prove fade, slide-up, slide-left, none/fade/slide/push and all four directions. Push uses an inert outgoing snapshot and actual scaled page distances, updated without resetting time on resize. Timing is bounded to 0–10000 ms; unsupported scale/exit and clamped fields have source-path static reports. Engine commit, undo/redo and saved HTML decode retain original fields. |
| Complete edit/print content; reduced motion preserves terminal semantics | Both browser journeys check visibility and absence of animations with reduced motion. Host print builds every slide in a disposable static surface; Portable print reveals all slides/steps. Preview uses an isolated DOM clone and leaves revision unchanged. Configuration uses typed operations through the existing Engine. |

Configuration is available in Host and full-portable; other profiles retain their
existing editing restrictions. Keyboard arrows/space step; PageUp/PageDown skip
slides; Home/End go to the boundary pages. Unsupported values are not stripped or
silently migrated. No new schema/profile is necessary: these fields and typed
operations already exist.

Verification results and the signed implementation commit are recorded in
`../TASKS.json` after all required gates complete. The original suite has 345
tests; F05 adds six tests. Blackbox task-start baseline is retained in
`f05-blackbox-start.json`.

Remaining limits: real Safari/Office/physical-device validation remains Q01 work.
PDF/PPTX animations are explicitly static, not native timeline exports. Scale and
exit effects are retained but not executed; timings exceeding 10000 ms are retained
and reported as clamped. Push snapshots omit live media players (including their current video frame);
media lifecycle remains managed by MediaController.
