The original R1 and week7-13 regeneration assertions remain unchanged and pass.
These assert that content-preserving replacement is still allowed. For an unlocked
protected object with a matching identity, the planner copies all current values
into its replacement. Hard locks and explicit request protection retain the
original instance. This avoids both stale-content overwrite and an incompatible
blanket ban on existing replacement workflows.

## Remaining boundaries

A14/A17 evidence here covers D01's contracts only. D02 parameter execution, D03
browser measurement, later visual maturity and actual Office-client fidelity are
not certified. Static capabilities intentionally remain unverified/unsupported.
The synthetic font notices cover name references only; no font binaries are
included. Callers supply accepted digest/license policies and ordinary asset bytes;
this package does not download, execute, silently migrate or silently upgrade packs.
