## Reproduction

Run from the repository root:

```sh
pnpm typecheck && pnpm build && pnpm test
node --test dist/tests/evolution-baseline.test.js
node scripts/evolution-baseline.mjs /tmp/c01-browser-rerun.json
pnpm blackbox:final
```

`node scripts/evolution-fixtures.mjs` deliberately regenerates the three synthetic
originals from the current build. Do not use regenerated bytes to silently replace
frozen provenance; a changed corpus needs a new manifest version and hashes.
Tests only write temporary output directories and preserve fixture bytes.
Browser reruns default to `/tmp/c01-browser-baseline.json`, preserving frozen data.

The browser reference uses headless Chromium on the recorded Apple M4 machine,
1440×900, file URLs and 12/30/100-page synthetic text/shape decks. Each deck has
20 fresh-process startup samples, 20 same-context reload samples and 30
Operation-Engine edit-to-two-animation-frame samples. Fresh process does not mean
OS disk-cache cold. This measures API-to-paint, not keyboard/IME latency. System
Inter fallback is explicit; no embedded font bytes or media are included. Fonts
and image readiness are awaited. It is not a real-Safari, lower-end-device,
Host-startup, physical-IME, or complete interaction/memory qualification.
E02 must compare candidates on the same setup and separately prove correctness;
future A20 scenarios are explicitly listed in the protocol.

The start blackbox report contains 67 green and 2 red cases. Existing reds are
`section-41:1` (Host download timeout) and `delivery:2` (editable browser journey).
At the original completion both remained release risks. The fix-round result below
supersedes that current-status assessment without changing the frozen reports.
