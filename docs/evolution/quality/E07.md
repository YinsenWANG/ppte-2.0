# E07 editor shell and offline parity evidence

Task baseline: `7c8b8e8` on `evolution`; 209 tests, blackbox 69 green / 0 red.

## Criterion evidence

1. `tests/editor-parity-journey.test.ts` runs the same keyboard journey on Host
   and a generated full Portable at 1600 and 700 pixels. It checks native
   pages/properties disclosures (Space, Enter, Escape, focus return), thumbnails,
   file input focusability, and selection tools hidden in presentation. Shared
   `editor-shell.ts` owns keyboard/file-focus behavior; shared object properties
   and existing text/gesture adapters continue to own their respective controls.
2. The legacy API test calls plain-text replacement with and without the optional
   revision, checks retained bold marks, rejects a stale revision without history
   growth, and undoes through Core. The browser test exercises `enterEdit`, refuses
   range formatting without a session and refuses viewer elevation. The migration
   test checks the runnable browser example and Skill notes. Legacy Host property
   controls delegate migrated text/paragraph/shape properties to the shared planner.
3. The shared browser journey starts with a new document (Host New; generated
   Portable from the same blank-document factory), edits Cherry Studio, bolds only
   Studio, changes whole-box font size, undoes/redoes, saves HTML, reopens, undoes
   again, presents with keyboard/API write rejection, exits, and exports .ppte.
   Exported semantic content must exactly equal the edited document. Host also
   saves and reopens native .ppte before performing the same presentation checks.

The existing `tests/host-completion.test.ts`, `tests/text-range-editing.test.ts`,
`tests/object-transform.test.ts` and `tests/image-editing-journey.test.ts` remain
unchanged and cover retained drafts/conflicts, composition contracts, pointer
cancellation, image import/crop/resource retention and persisted undo. The first
full run caught Escape propagation breaking the existing image cancellation test;
the shared shell now honors already handled Escape and preserves propagation to
document gesture listeners. No assertions were weakened.

Browser screenshots and traces are generated under `artifacts/e07/` by the node
suite. The committed verification JSON records final counts and artifact hashes;
blackbox start/final reports retain build identity and browser environment.

## Scope and remaining risks

- Automated Chromium coverage passes only the applicable M1 engineering scenarios.
  A21 product-owner/two-user timed usability sessions, physical Chinese IME,
  real Safari and low-performance physical devices remain unverified.
- Portable creation means generating a fresh independent browser document through
  Host/CLI. It does not add a project-picker/New command to recipient copies.
- Export in this journey is the editable HTML and semantic .ppte source. PDF/PPTX
  export stays with existing CLI/export suites; real Office fidelity is unverified.
- Narrow-window folding is tested at 700 px; complete mobile authoring is not a
  supported claim. Host-only review/design tooling remains Host-only.
