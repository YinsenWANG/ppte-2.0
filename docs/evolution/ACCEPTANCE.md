# PPTe 下一阶段验收矩阵

版本 1.0 · 2026-09-05 · 全部为待执行的验收规格，不是测试结果。

本矩阵与 [实施方案](./IMPLEMENTATION_PLAN.md)、[任务清单](./TASKS.json) 配套。每条测试报告使用固定的 Axx 编号；不得因测试尚未实现而将其标为通过。执行前固定 fixture digest、应用版本、runtime buildId、操作/文档 profile 和浏览器/设备。

## 验收规则

- **状态仅取** not-run / pass / fail / blocked / unverified / not-applicable。not-applicable 必须有对应 capability 与原因；不能用于规避已声明支持项。
- **证据最少包含** 场景、输入摘要、操作序列、期望与实际、revision/history、环境、产物路径/摘要、执行人或自动工具。浏览器行为另附截图或 trace；实机验收另填实际应用及版本。
- **发布顺序** G0 → G1 → G2 → G3 → G4；测试只对该阶段新增/承诺能力要求成功。表格、视频等未交付能力在早期必须准确报告降级，不得提前显示支持。
- **阻断原则** 数据/历史损坏、越权误伤、保存失败、放映可编辑、资源丢失、能力虚报直接阻断；视觉建议不能抵消这些错误。
- **文件保全** 原始失败文件只读，测试写新目录；fixture 应可合法公开并去除私密内容。不能以清空历史或重制全页图片来让用例通过。

## A01 可选字段与序列化逆操作

关联 C01/C02/C06；Core 与所有序列化边界。

**准备：** 原本无背景、已有 solid/gradient/token/none 背景各一页；若 schema 不支持某种值，则验证明确拒绝。加入可选元数据、嵌套 overrides、空集合/字段缺失的边界组合。

**操作：** 设置/删除/改值 → preview → commit → JSON roundtrip → undo/redo → checkpoint → 重开 → undo/redo；单页与多操作事务均执行。

**通过：** 每步 canonical revision、字段存在性和 history 链符合预期；none 与继承背景不同；保存重开的撤销结果一致。对所有新增或修复操作执行生成式序列测试，seed 固定并记录失败最小化样例。

**负例：** set/unset 冲突、未知字段、删除 id/elements/rootOrder、非法值与越界路径均拒绝，无文档或日志副作用。

## A02 错误 inverse 与事务原子性

关联 C02；Core preview/commit、journal。

注入可执行但错误的 inverse、序列化会丢值的 inverse、过期 proof、被更改的 transaction digest。验证返回 INVERSE_ROUNDTRIP_FAILED 或相应冲突；document/revision/history/redo/journal 与之前完全相同。正确 proof 可复用但只能用于它绑定的事务与 beforeRevision。记录 proof 耗时，不能只在测试配置开启校验。

## A03 新旧协议与所有持久边界

关联 C02/C03/E08/F01/Q02；CLI、Host、Portable、checkpoint、patch。

**矩阵：** 合法旧 1.0 文件；新 1.1 history 但旧语义对象；仅 redo 含新操作；新 patch；含 Run 新字段；Table v2；未知 profile/操作/required extension；不匹配 manifest 版本。

**通过：** 新 reader 接受声明支持的旧/新版本；未知能力严格按登记规则只读/拒绝，不能推断成已知迁移。profile 推断覆盖 document、undo、redo、patch。保存任何入口都不漏最低能力。原文件摘要保持；迁移写新文件并附报告。旧 reader 对不认识的新版本不静默改写；如果无法显示只读预览，准确说明而不承诺可渲染。

## A04 损坏历史、恢复与保存故障

关联 C03/C06/E06/Q02；文件与恢复系统。

**正例：** 快照有效/历史失败；可信最近后缀；精确匹配的前置基准+完整 forward 链；无基准的重新开始历史；redo 单独损坏。验证只有已证实的内容/后缀可用，重建每一步 afterRevision 与最终 head 相等。

**负例：** 错 documentId、错 beforeRevision、缺资源、错误 hash、损坏 history checksum、未知操作、相似但非精确基准。不得猜测重建。原 `.ppte`、journal、CAS 和诊断保留，首次失败处停止，不跳过坏事务。

**故障：** 恢复/保存写入前、临时文件后、替换前注入崩溃；磁盘拒绝、浏览器权限/配额拒绝、下载取消。无半成品宣称成功；原件 hash 不变，草稿保留。浏览器新恢复 namespace 不覆盖原 tail/base/资源引用；快照不完整仅只读诊断，不擅自删除坏对象。UI 区分内存修改/恢复记录/写盘成功/已下载副本。

## A05 交付身份与不覆盖行为

关联 C04/C06/Q02；打包、delivery、生成后的 HTML。

相同身份与内容重复交付应复用且字节不变；分别只改 runtime、renderer、字体政策/字体字节、资源字节、history、redo、capability、profile、导出参数，均不能返回旧副本成功。旧 HTML 缺身份、metadata 被改、脚本被改、内容被接收者修改分别测试。

新副本只使用受控同目录命名，返回真实路径；同名不同文件不覆盖。旧 API 省略 collisionPolicy 仍为 error，新流程显式 versioned-copy；与旧 replaceExisting/confirmed 参数冲突时报错。短 hash 路径碰撞延长 hash/后缀并原子创建。另单独改变受控 shell/CSS/CSP 或兼容 descriptor，旧报告必须失效。明确覆盖路径原子替换并可恢复旧版本。路径穿越/任意目录扩张拒绝。摘要不是数字签名，报告不声称发行者认证。

## A06 两端干净放映与模式竞态

关联 C05/C06/E01/E07/F05/F06；Host 和生成后的 `file://` Portable 必须使用同一旅程。

带当前输入草稿进入放映；全屏正常/拒绝/系统退出；快速进入退出；晚到 fullscreenchange；横竖窗口、缩放与多个放映循环。检查无 toolbar/sidebar/inspector/notes/footer 编辑泄漏、无虚线/选框、所有文本不可编辑、没有编辑焦点。

放映中通过键盘、paste、拖入、pointer、undo/redo、公开 API 尝试改文档；全部被同一守卫拒绝，revision 和 history depth 不变。媒体、链接、退出按钮不触发意外翻页。Esc 回到原模式与当前页，可继续编辑和保存。仅退出自己拥有的全屏；viewer 不能启用 edit。

## A07 放映前输入收口

关联 C05；两端 DOM/IME。

文本有未提交内容时点击放映、换页和保存。正常情况恰好提交一次；验证失败保留原草稿/选区、停留可修正模式；composition 进行中等待用户完成，不能截断候选词。多个待切换请求只执行最新有效请求，取消后 compositionend 不能重新强制进入放映。

## A08 精确文字范围与格式

关联 E01/E02/E03/E04/E07/E08；RichText 纯函数与两端浏览器。

选中“Cherry Studio”中的“Studio”设粗体/强调色；跨段、反向选区、混合 marks、折叠光标、整框选择分别测试。选区外内容、marks、未受影响 run ID 不变；正确更新拆分 ID 和 PositionMap；工具栏抢焦点后恢复准确范围。

E03 要求基础 marks 和整框字号；E08 才要求选区字体字号。新增 Run 属性要测继承、mixed、清除格式、字体 token/缺字、测量、HTML/SVG/PDF/PPTX；未实现前 UI 不能宣称支持。每种变换撤销、保存重开后相同。

## A09 IME、粘贴与唯一历史

关联 E02/E03/E07；实际中文输入法人工验证 + 自动事件合同。

中文连续组合输入、候选选择、取消、emoji ZWJ、重音组合、中英混排、跨段粘贴、纯文本/受支持富文本粘贴。compositionend 后重复 input 不双提交；候选期按键不误当翻页/退出；不得拆代理对/完整字符。

输入 → 加粗 → 输入 → 保存 → undo/redo 的顺序可预测。只有 Core 历史生效，重开仍可撤销；浏览器/库历史不能抢一次操作。输入分组边界固定并记录，自动测试不能替代真正 IME 的最终验收。

## A10 草稿失败与并发冲突

关联 E02/E03/E07；编辑控制层。

编辑期间注入 commit 拒绝、保存错误、相关/无关对象 revision 更新。无关更新仅在目标 hash 未变时重新规划；目标变更进入冲突，保留本地草稿，不覆盖远端/Agent 修改。活动 DOM 与选区不被无关渲染替换。重试成功后才清理 draft；放弃草稿是显式可理解操作。双击保存 + compositionend + blur、字号与 blur 并发只提交一次；flush 失败后 undo/换页/切模式不继续执行，composition 中不执行文档撤销。

## A11 对象手势、锁定与精确排版

关联 E01/E04/E05/E07；两端相同指针与键盘脚本。

移动/缩放/旋转/多选/扁平组合/图层/对齐分布，覆盖 50%/100%/200% 舞台缩放。100 次 move 只一笔最终事务；零位移零事务；Esc/pointercancel/lostcapture 零提交。框尺寸改变默认不改字号；图片比例行为可见。

锁定成员、混合多选、越权组、无效几何拒绝且整组不动。对齐范围是选择或画布，吸附不改别的对象。相同逻辑坐标的操作在不同缩放结果一致；撤销重开仍一致。

## A12 图片、背景与资源闭环

关联 E04/E06/E07/F04；CAS、两端导入与导出。

拖入/文件/剪贴板导入相同图片，去重但引用独立；裁剪/替换保持目标身份和指定几何。背景图片、纯色/渐变/主题继承回退都可撤销并重开。

解码错误、拒绝 MIME、损坏字节、取消、配额失败不产生半对象；撤销不能删掉其他对象共用资源。资源保留集合含当前文档、undo/redo、journal、draft/jobs；必须测试插图→撤销→保存重开→重做，history 引用的字节不丢。替换/删除后的 URL 与资源生命周期有证据；离线副本包含所有需要的字节。大素材处理建议明确，不能静默丢图。

## A13 表格与事实稳定性

关联 E08/F01/F02/F03；组件、Core、UI、导出。

v1→v2 迁移保留表头/caption/scalar 类型/元素 ID；建立 cell IDs。测试改值、行列插删移动、尺寸、矩形合并拆分、TSV、非矩形输入、空表、中文长内容及长数字。未改格身份与事实引用不变；结构删除引用目标需影响审阅。

合并不得丢被覆盖格的值；非法交叉/非矩形合并拒绝；泛化 props 更新不能绕过不变量。表格组件更新只影响目标。Office 中实际可编辑单元格，原生 table part 内容与输入一致；图片或标签不能计为 nativeTable。E08 仅共享兼容/原生文本相关子项，其余表格子项在 F01–F03 执行。

## A14 配方执行、容量与确定性

关联 D01/D02/D03/D04/D07；编译器与实际浏览器测量。

每种声明的 variant/constraint/qualityRule 至少正常、冲突和边界用例；未支持的显式拒绝。类型/required/min/max/keepTogether/baseline 与有界 repeat 逐项有效，槽位不能被 first-fit 错占。固定输入、版本、seed、font digest 后输出一致。

每个风格角色格提供正常/接近上限/超载样例，超载明确失败或换版式/拆页提案；全部内容块已安置，无隐式截断或缩字。真实测量等待字体/资源；无浏览器只报告 unverified，D04 成熟覆盖格与 G2 不能因此通过。正常/边界必须留本构建和固定字体的截图；字体资源超时算该次失败，fallback 用明确新配置重验。有意图文覆盖按配方关系验收，非预期遮挡/缺字/越界阻断。M2 表格压力只验证现有呈现与语义保留，Table v2 归 M3。

## A15 安全换主题、配方与 Skill 调用

关联 D04/D05/D06/D07；Controller、设计编译、CLI/Skill。

八条序列：改字后换主题；局部格式后换字体；锁几何后重排；换图裁剪后换版式；人工加形状后美化；4 列改 3 列；重排后撤销重开；缺风格包环境打开并导出。

当前 Document 是真源；手动文字、局部 overrides、锁定/受保护内容、语义 ID、事实和素材不变。容量不足给提案，不删第四项；恢复风格默认是显式命令。绑定失效不猜测。Skill 读取索引→候选→选中配方、用真实代表页、最多两轮修复，所有内容变更经过 preview/commit；不要求用户重复批准已授权的制作范围。

## A16 视频、步骤与现场工具

关联 C05/F04/F05/F06；至少两种声明支持的视频素材及失败素材。

验证真实 src/Blob 绑定、loadedmetadata、手动 play、pause、ended；离页暂停、返回续播、退出释放、解码/自动播放拒绝可见。单 HTML 和离线目录均在声明的真实浏览器入口断网实测；目录包应含 HTML 入口、manifest 和 media，区分打包时字节校验与打开时能否复验。若 file:// 受限，不声明该路径支持，保留验证的大 HTML 或 Host 方式。

step 1→0，step 0→上一页末步，nextSlide/previousSlide/gotoSlide 与首末边界符合合同；编辑/打印显示所有内容。减少动态效果后终态与步骤一致，未实现动画参数保持降级声明。

黑屏/激光笔/计时不改 revision。双屏弹窗拒绝、断连、重复乱序消息、错误 token/来源、观众窗关闭可恢复；备注不出现在观众 DOM。C05 只执行基础步骤/模式子项，真实媒体与现场工具随 F04–F06 验收。

## A17 跨格式与报告真实性

关联 E08/D01/D03/D04/D06/D07/F03/F04/F05/Q01；所有交付目标。

检查 HTML 编辑、HTML 放映、PDF、图片 PPTX、语义 PPTX 的每项 capability 与实际表现。原生文本/形状/图片/图表/表格分别证明；视频/动画静态化明确报告；字体替代与布局风险真实可见。报告必须绑定源文档、history/资源、runtime/renderer 和配置身份，修改任一项使旧报告失效。

选定支持的 PowerPoint/Keynote/LibreOffice 客户端后，分别记录实开、原生对象编辑、重存、文本顺序和视觉；未选支持的客户端不暗示兼容。没有实际 Office 环境时保持 unverified，不能仅 unzip 就宣布全面保真。

## A18 增量更新与异步过期结果

关联 E03/P02/P03；浏览器与 Core。

编辑第一页文字，未改页 DOM 身份不变；当前 IME 节点和其他页媒体位置不被重置。资源 hash 不变不重复生成 URL/解码；缩略图只失效相关页。窗口化不影响搜索、页序、打印和全量导出。

增量索引与全量重建对照完全一致。Worker 任务取消、超时、输入改变、乱序返回、队列过载、关闭文件后返回均不能写入过期结果或泄漏资源；作业只返回提案。E03 执行活动文本正确性子项，全面性能部分由 P02/P03 完成。

## A19 npm、Skill、版本与离线交付

关联 C04/C06/D06/Q01/Q02；干净临时目录与安装包。

从实际 tarball 安装，不借源码工作区依赖；记录应用版本、包摘要、runtime buildId、Skill 来源。安装后断网执行 compile→inspect→preview→commit→undo/redo→deliver；不启动 MCP、不设模型密钥、不靠守护进程。渲染导出缺浏览器时清晰提示按需安装，基础命令仍可用。

另测原生 Skill 安装到新目录、冲突目录保护、升级说明。CLI/Host/Portable 关于信息/报告版本一致。GitHub 推送、npm 发布、本地安装和副本升级各有真实状态；未执行的操作写未执行。

## A20 真实浏览器性能

关联 C01/E02/D03/F04/P01/P02/P03；固定 12/30/100 页材料。

记录真实设备、浏览器、视口、字体、文件 hash；启动冷/热分开。场景至少 30 次、启动至少 20 次，保留原始采样与 p50/p95；测交互/画面而非仅 HTML 生成。输入、拖动、翻页、撤销、保存、媒体往返、内存与包体分开。

冻结预算后再评候选，不随失败调高阈值。达到速度预算同时满足无关节点稳定和文档正确性。较低性能实机与真实 Safari 没测时标 unverified；CPU 节流可辅助，但不替代设备证据。E02/D03/F04 只要求本模块开销/容量采样，不提前要求整个产品预算。

## A21 人工完整旅程与可用性

关联 E07/F02/F06/D07/Q01/Q02；产品负责人及至少两名目标使用者。

10 个任务：改字、局部加粗、字号、换图、裁剪、对齐、改表格、保留锁定换布局、重开撤销、演讲交付。文字/图片/对齐/重开/基础放映从 M1 开始，保护式换布局从 M2，表格与媒体现场工具从 M3。G2 仅测适用子集，未到阶段记 deferred、不计通过；G3/Q01 执行完整十项。记录成功/失败、耗时、求助和修复操作。

键盘可到达常用控件、焦点可见、弹层可退出、按钮有可访问名称。Host 桌面主编辑与 Portable 窄窗口有合理折叠，不将小屏完整创作作为未测承诺。任何数据丢失、误伤或无法退出放映阻断；美观评审提供页/对象证据。

五类材料×两种用途的同题基准保留首次产物、修复版本和人工耗时；同 Agent/预算至少两次生成看波动。首轮建立基线，不编造百分比或“完美分数”。

## A22 条件探索门禁

仅 X01/X02，非 G0–G4 必做项目。

QuickJS 先有实际无法合理声明式表达且需要不受信任代码隔离的需求证据；实验验证总耗时、内存/栈/时间/输出/日志/宿主调用预算、死循环与取消，成品无需扩展引擎。多人协作先证明文件级 patch 无法满足，验证权限、冲突、undo/redo、离线/重连与保护语义。条件不成立则保持 deferred，并记录原因；不得为了完成任务表强行引入依赖。

## 报告骨架

以下字段为报告协议示意，不是已完成证据：

```json
{
  "reportVersion": "1",
  "acceptanceId": "A06",
  "taskIds": ["C05"],
  "status": "not-run",
  "buildId": null,
  "fixtureDigest": null,
  "environment": null,
  "executedBy": null,
  "cases": [],
  "artifacts": [],
  "unverified": [],
  "blockers": []
}
```

每个阶段的 gate 报告引用所有必要 task/case 结果，而非直接手填整体 pass。任何旧 build 的测试结果只能做历史对照，不能算当前产物的发布凭证。
