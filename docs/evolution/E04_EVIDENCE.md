## Scope and remaining risks

- The shared property surface is available in Host and full-portable; other
  Portable profiles keep their existing supported command subsets. Presentation
  hides the panel and the controller remains the write guard.
- Background controls use the current schema's none/solid/token/linear-gradient
  paints and reliable unset. They affect only the current page and do not mutate
  canvas defaults or global theme tokens. Image-background/CAS work remains under
  E06/F04; this UI does not claim image-paint support.
- Shape insertion/type controls expose existing preset shapes, not arbitrary
  paths. Polygon creation requires points and is not offered by the basic panel.
- Shortcuts are scoped to the focused property panel and ignored during IME or
  when a form field has focus. Property DOM survives content-only draft flushes;
  refreshed callbacks avoid stale Host readiness state; duplicate change/blur
  events do not submit the same numeric value again.
- Run-level fonts, CRDT, realtime collaboration, nested group coordinates and
  arbitrary widget execution remain outside this change. No dependency was added.
- Automated Chromium and exporter checks do not replace real-device Safari,
  operating-system IME, or physical Office visual acceptance under Q01/Q02.
