# R6 · 版本输入与确认

承接 main 验收基线 `f5ba1900cb1467126cc3edd911ce762413280cdb`，本轮父提交 `2861999`（R1–R5 已在当前分支）。历史 REPORT、原型、审计样稿与两份探针均保持原样。

版本面板使用统一的产品 HTML dialog：命名与重命名提供名称字段、1–200 字校验、取消、Enter 提交和 Esc 返回；容量在一个表单中展示当前占用、自动版本数、容量与清理后果。错误保留输入与面板，提交时重新检查编辑/保存/组合输入状态。取消不会改变数据，成功或取消均返回触发控件；删除触发控件后返回“关闭版本历史”。弹窗默认焦点落在首个输入，恢复/删除默认焦点落在取消，沿用浏览器 dialog 的模态焦点约束。

列表保留预览入口，将命名/恢复/删除收进每个版本的“管理版本”展开区。恢复确认包含目标名称、时间、保留恢复前内容及后续历史；删除确认明确仅删除一个目标版本、写入后跨会话不可恢复、当前内容与其他历史不变。列表及面板显示尚未写入文件，容量/删除也纳入保存修订。样式按 DESIGN.md 冷灰/白、强调色、16px 弹窗圆角组织，仅作用于产品节点。

实测发现 Esc 原本会触发全局退出编辑；本轮让编辑与保存全局快捷键跳过产品 dialog，防止 Esc、T、Delete、撤销或保存误操作背景。原生文件权限选择器没有被替换或模拟。
