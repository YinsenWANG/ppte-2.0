# UI01 — 三模式与布局外壳

本轮只完成 UI01 的代码与自动化验收。UI04、UI07 及其后续任务保持 pending；S06–S08 的 partial、N01–N04、性能、媒体、原生授权、系统 IME、Safari 和人工验收缺口均未关闭。原型没有作为产品代码或验证对象使用。

## 实现

- 默认 file:// 阅读，页面栏收起；单页居中适应空间，底栏显示当前页、导航和帮助。下载、复制到另一目录后用独立 Chrome 进程打开仍为阅读。未修改时隐藏保存提示，进入编辑不索取权限，也不制造草稿状态。
- 稳定的 56 px 文档栏、阅读/编辑模式组、46 px 独立编辑工具栏；204 px 页面栏和按上下文出现的 264 px 属性栏。未选择不占属性栏宽度；选中对象展开，关闭属性释放空间；页面设置主动展开。继续使用现有 Commands、输入历史、作者 iframe 和 Shadow DOM 缩略图，没有引入固定坐标内容模型。
- 阅读适应样式由 `reading.ts` 持有，全部标为 transient；离开阅读即移除。切换模式不重建作者 DOM；序列化仍走原清理管线。进入编辑和放映退出保留当前页；恢复对象焦点不滚回另一页。
- 彻底删除观众放映菜单 DOM、HUD 和鼠标/Tab 召回。鼠标静止隐藏指针；保留键盘翻页、黑屏、视频交互、独立演讲者窗口，横向触控滑动避开内容交互元素。演讲者窗口被阻止时不向观众画面添加提示。
- 全屏拒绝和同步抛错均保留纯净窗口内放映；Esc 回到进入前模式。记录全屏所属状态，处理实际退出与授权延迟完成后的 Esc 竞争。打印和放映在测量作者页面前清除阅读适应层，保留原页面比例及 Grid/Flex。

## 既有测试调整的原因

没有删除测试或降低阈值。

- H04/S01 原“鼠标召回菜单”正断言与新规格冲突，改为更严格的菜单不存在断言；黑屏 PNG 全像素、媒体、步骤、演讲者预览和退出断言保留。
- H03 未选择对象时返回编辑不再强制出现空属性栏，改验属性隐藏且编辑外壳开启。键盘回到文档栏时焦点为模式组的第一个“阅读”按钮，并验证当前“编辑”状态。
- S03 背景操作先点击“页面设置”，保留原背景值、撤销、保存重开与 PDF 断言。
- H01 原生画布保真测试根据新的顶栏和底栏计算工作区，等待适应完成；逐元素几何、字体和 PNG 字节完全相等断言全部保留。
- S01 未修改时检验隐藏的状态文本和不可见性；下载后仍检验原文件未覆盖。

首轮失败原始日志保留在 verification 中，包括布局、模式顺序及相关修复过程。最终命令、状态、平台、源提交与日志摘要见 `verification/result.json`。
