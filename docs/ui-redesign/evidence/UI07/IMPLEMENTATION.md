# UI07 — 跨会话单文件版本历史

生产实现使用作者 HTML/CSS 完整检查点，不引入坐标模型、演示 IR、容器、旁路文件或服务依赖。更多菜单的“版本历史”在阅读模式提供查看／隔离预览；编辑模式提供保存命名版本、命名、恢复、删除和容量管理。原有本机备份恢复按钮从产品菜单移除，持久版本不再与会话撤销／浏览器草稿混称。

## 协议与行为

`ppte-history-index` 是 schemaVersion 1 轻量索引，含文档身份、版本 id、时间、名称、来源、SHA-256 内容块、资源引用及恢复来源。内容块和历史专用资源放在 inert template；完整检查点之间没有差量依赖。S06 的媒体摘要与 `ppte-media` 复用：当前资源与历史资源的并集只存一份，内容摘要相同复用块；每个块不包含产品脚本。复制唯一文件并启动新浏览器进程即可恢复，不读取原缓存。重新读取磁盘时内容和历史一并替换；关联文件还比较打开时的历史，避免仅内容相同而覆盖不同历史。

启动校验轻量索引，不解析旧 HTML、验证全部历史媒体摘要或渲染旧页。预览时只校验目标检查点、其资源摘要与引用，经过既有 cleanContent 安全边界，再使用无脚本／无同源权限的 sandbox iframe 和已有内容 CSP。关闭预览销毁 iframe。恢复先验证目标并原子地保留恢复前检查点；容量或资源错误时当前内容不变。恢复保留目标及后续版本，成为新内容修订，仍须保存；恢复前条目记录目标 id。

默认最多 20 个未命名自动版本，变化后自动版本间隔至少 5 分钟。默认历史额外容量 16 MiB，按转义后 HTML 传输字节计量，不计当前内容必需资源。超限只回收最旧的未命名自动版本；不能容纳时拒绝新增历史但继续当前内容保存，并显示可操作提示。命名／恢复前版本不自动删除。管理上限可调整为 0–200 个自动版本、1 KiB–128 MiB。另有索引 1 MiB、1000 条索引记录、单检查点及资源展开 32 MiB 安全上限；不存在压缩解压或差量链。用户删除按 1 个版本确认，回收只影响无人引用的历史块和历史资源。

所有原文件写回与下载继续经过 UI04 控制器和生产 encode。历史管理阻止在 IME 未完成或写入进行中改变版本；序列化不会自行确认写回。条目区分已载入／已写入、仅打包下载、尚未写入。下载不含历史为明确操作，不更改当前工作历史，不携带历史专用资源。未知／截断索引作为惰性原始数据保留，仍可保存当前内容；损坏目标在预览时显示不可恢复，其他内容继续可读。CLI 再增强和已有可选本机保存接口也保留内嵌历史，未增加必需服务。

## 证据分层和未关闭项

Chrome 152 headless 的 file:// 产品操作、下载、独立进程与截图是浏览器自动化实测。文件接口桥接为 Playwright binding + 实际磁盘文件，不是原生选择器授权。Safari、原生授权、系统 IME、屏幕阅读器、独立设备和真人评审没有记录：null + pending，不能由 mock 或本轮测试关闭。

历史按需恢复和单文件去重已有实现；**S06 当前编辑 DOM 仍使用既有 data URL 展开路径，当前页媒体按需解码／生命周期优化尚未完成**。本轮没有把历史媒体批量展开到当前文稿，也没有将 S06 的旧缺口标成通过。S04 输入／翻页 p95 未达标、N01–N04、九对同模型比较和真实低性能设备数据继续 pending。媒体证据使用真实编码的工程栅格和可播放 WebM，不冒充用户照片或审美人评。UI07 的严格共享资源运行时条款因此仍有 code 层缺口，TASKS.json 保持 partial，不能声称本补充全部完成。

性能 JSON 分别记录首次打开、版本创建、下载、全新进程打开、预览、恢复及文件字节数。较大 PNG 用文件接口桥接实写磁盘，记录单次总耗时。引用 S04 保存 p95 852.8 ms / 1500 ms 预算但明确工作负载及统计口径不同，不据此宣称可比基线或所有门槛已达标。

首次完整回归发现阻止带历史文件重新读取会破坏已有冲突恢复测试；已改为同步替换内容和内嵌历史。保留 `verification/first-test-failure.log` 和修复后回归日志。后续全量验证以 `verification/result.json` 为准。
