实现位于 `packages/html-editor/src/edit-canvas.ts`，由 workspace 统一调度。视图样式均标为 transient，未修改任何作者节点的持久布局声明。每次适应先撤掉视图 CSS，在随窗口变化的作者文档视口重新测量，随后恢复当前页显示；缩放和属性面板不会固化响应式作者的内联尺寸。固定画布超出窗口时扩展 iframe 容纳画布；响应式内容继续使用作者的 vw/vh、媒体查询与 Grid/Flex 声明。单页视图使用临时测量尺寸，下载时全部移除。

缩放作用于外部 iframe，作者坐标内保持 CSS 像素，已有移动/排列/插入命令无需换算第二套内容模型。工作区根据滚动偏移摆放并裁切 iframe，未重挂载文档，文字选择、属性焦点和作者节点身份保留。输入完成后合并到下一动画帧重新测量流式高度。切换阅读、放映和打印时清理编辑视图。

底栏帮助弹层定位同时去除默认段落外边距，避免其可见矩形越出窗口；未改变菜单行为或删除旧断言。
