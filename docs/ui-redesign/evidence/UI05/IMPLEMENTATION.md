# UI05 — 适配与可访问性

产品实现与自动化验收记录，非原型验收。逐项结果、命令日志、实现提交和环境见 `verification/result.json`。

- 1440 / 1024 使用 204+264 / 170+238 px 页面与属性栏；820 及以下打开属性先收页面栏。390 默认收页面栏，页面/属性抽屉互斥；抽屉打开时作者 iframe inert 并从辅助技术树隐藏，关闭后恢复。三模式和作者 Grid/CSS 保持原管线。
- 顶栏、编辑工具和底栏按实际高度布局，允许换行；保存状态完整换行，弹出面板按可用视口避让并滚动。窄屏与 coarse pointer 使用至少 44×44 px 按钮命中区，包含表格网格、色板和对象尺寸手柄；属性输入、帮助和保存开关增加触控空间。
- 插入与更多菜单支持方向键、Home/End、Enter、Esc；Tab 关闭后沿触发器继续，不卡在已隐藏元素。更多菜单暴露 menu/menuitem 语义，启动版本弹窗前关闭菜单，弹窗关闭返回可见触发器；保存和属性面板 Esc 返回入口。作者 iframe 内点击也能关闭菜单。
- 图标保留名称与 tooltip，模式有 aria-pressed，页面栏入口有 aria-expanded/controls，新增底栏与版本弹窗可见焦点。重要文字使用实测 >=4.5:1 的颜色，保存状态亦在测量中。减少动态偏好限定于产品外壳，不修改作者作品。

四项 acceptance 分别由 `tests/ui05-accessibility.test.ts` 的四个 node:test 驱动当前 dist 产品，在安装的 Chrome headless 中离线 file:// 操作；无 force click。截图、触控命中矩形、对比度计算及浏览器记录一并归档。第二项以 1440×900 的一半 CSS 布局视口 720×450 验证 200% 重排，加 390×844 和 20px 外壳字体压力测试；这是等效自动化，不冒充原生浏览器缩放菜单或系统大字体实测。原生缩放、系统大字体、物理触控、屏幕阅读器、Safari 与人评均 pending。

回归修正：更多菜单从 button 改为 menuitem 后，UI07 与 H04 的定位器更新，并在关闭菜单后显式重新打开；原断言全部保留。首轮全量的两次 UI07 旧定位超时，以及定向回归发现的菜单语义依赖异步 toggle 竞态，保留原日志。语义现于创建/新增项目时安装，消除可访问性状态的延迟。触控表格网格提高样式选择器特异性，避免后插入的菜单桌面宽度覆盖触控宽度，并断言无水平滚动。

本轮不关闭 UI07 当前媒体生命周期、S06–S08、N01–N04 剩余的真实性/性能/原生环境缺口；不声称 UI06 或整体人工验收完成。不 push。预存的流水线 brief 留在原处并加入本地 exclude，未删除。
