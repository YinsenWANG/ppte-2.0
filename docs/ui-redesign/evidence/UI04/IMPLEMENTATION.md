# UI04 — 原文件保存与自动保存

范围：生产 HTML 编辑器；保留作者 HTML/CSS、已有 Commands、单文件资源管线与默认阅读。原生文件写入复用 fileAdapter，未增加服务依赖。历史版本由 UI07 承接，本任务不把草稿或旧 loopback 缓存称为持久历史。

实现：顶栏“保存”和可点击状态打开保存面板，显示文件、关联情况、默认开启的自动保存开关、最近成功时间、关联入口、下载和隔离只读磁盘预览。系统选择由主动保存触发，取消保留修改，不自动反复弹窗。不支持原生选择时提供下载。下载不清除 dirty、不确认文件修订。恢复草稿明确尚未写入文件。

单控制器缓存完整内容修订供写回、草稿、下载使用。输入停顿 1 秒，持续输入最长 10 秒尝试；草稿原有 200ms 检查点保留。关闭自动保存不影响草稿和手动保存。写入流 close 和磁盘读回校验完成才确认对应修订；写入中更改不会被旧确认清除，手动请求合并进下一次写入。失败/权限撤销/冲突锁定到明确重试或重新读取。关联校验文档身份、内容、持久修订，绝不按同名覆盖。重新读取使序列化缓存失效。

组合输入期间不序列化草稿、下载或写回，compositionend 后保存完整事务。现有拖动/尺寸操作只在 pointerup 执行 Commands 事务；表格批量操作同步提交，未引入半操作快照。浏览器卸载仅草稿最佳努力与离开提醒。不会在重开时伪造关联或权限；重新关联是当前保守实现。

## 证据边界与未关闭项

Chrome headless 产品操作截图、下载与全新进程重开为自动化浏览器证据。文件接口 bridge 使用 Playwright bindings + Node 磁盘操作，绝非原生授权证据。系统 IME、原生 picker 允许/取消/撤销、Safari、跨设备、屏幕阅读器和真人评审均 pending，没有可用操作记录（值 null）。未用这些缺口取消 N01–N04、S04 性能或 S06 媒体缺口。

File System Access 没有本项目可用的操作系统排他锁；保存前及创建流后双重校验、close 后校验可检测已观察到的冲突，不能保证最后检查至写入之间不存在外部竞争。文件句柄、路径和权限不写入交付 HTML。支持能力最终以原生系统实测为准。

下一步原生实测：file:// 打开→未关联编辑→选择当前文件并允许写入→停顿/持续输入/系统 IME/拖动→检查磁盘内容与未选文件哈希→关闭整个浏览器→新进程重开→撤权/外改/再授权与下载恢复。按 Chrome/Safari 分别记录，不能用桥接结果代替。
