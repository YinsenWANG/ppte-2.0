## 实现

`insertion-layout.ts` 在作者文档中识别实际父内容区及其布局。父容器的可见直接子对象均为绝对定位时，仅将新增对象设为绝对定位，在参考对象后方优先搜索空白；必要时缩小新增图片/形状的显示尺寸，保留原图数据和宽高比。表格在这种画布上采用有限初始宽度。若选择的是独立媒体包装节点中的 SVG，则插入到包装对象旁，而非挤入其内部。没有修改全部作者节点的定位、样式或层级，也不再通过抬高 z-index 遮挡文字。

避让同时检查可编辑文本对象、真实文字 Range（包括混合容器直接文字和嵌套行内文字）、图片、视频、SVG、表格及独立形状；检查新增对象是否被祖先裁切。没有只检查 h1–h6。位置无法成立时，移除候选对象，不入撤销栈，显示“没有足够空白……插入已撤销，请选择其他内容位置或新建页面”。非受支持定位基准亦有对应撤销解释。

Grid/Flex 保留其原生流和 order / align-self；普通块流用真实 DOM 顺序操作，支持 Alt+方向键和“提前一个对象 / 推后一个对象”，以及外边距与对象左/中/右对齐。行内图片的对齐操作会把该对象变为块级，以使自动外边距真实生效。带裁切边界的流式画布同样会按剩余空间缩小新增媒体，原 12 页稿因此仍可插入图片。失败插入会恢复原有布局。

鼠标选择非文本对象后显式把键盘焦点交给对象，修复 pointerdown 阻止默认行为后 Alt+方向键仍留在外层工具栏的分支。单元格属性提供“选择整个表格”，使整表几何调整和单元格编辑都有真实鼠标入口。移动、尺寸、流式顺序和插入继续使用现有历史与完整 HTML 保存链路。
