# PPTe UI 设计：把空间还给内容

版本：UI 1.0 · 2026-09-07 · 待人工评审，尚未接入产品。

## 1. 设计依据与交付边界

参考用户提供的飞书幻灯片截图：清晰的页面导航、低噪声工具区、大面积中性工作台。借鉴其分区与信息密度，不照搬工具全集或增加协作、评论、公式等没有当前需求的入口。截图是参考，不代表已经审查飞书现行全部产品行为。

本设计承接 [人工反馈 U01–U04](../audits/2026-09-07-main-61310c7/USER-FEEDBACK.md)、[独立审查 N01–N04](../audits/2026-09-07-main-61310c7/REPORT.md) 和单文件方案；这里明确的 UI 细节优先于旧文档冲突描述，非 UI 的性能、媒体、可靠性、事实保真等要求仍保留。旧报告不改写。

交付包括 [可运行原型](UI_PROTOTYPE.html)、本设计规范、[执行与验收清单](TASKS.json)。原型演示 UI 与操作关系，不是产品修复，也不是可以替换原有 HTML 编辑器的实现。原型采用固定示例画布方便交互演示；生产代码必须保留任意作者 HTML/CSS 的布局合同，不能移植原型的数据数组或绝对定位方式覆盖作者内容。

核心方向：**常驻 UI 少，关键入口明确，深入操作随上下文出现，内容始终占据主位。** 成稿的视觉语言与编辑器分离。编辑器采用白与冷灰、少量蓝紫作为操作强调；示例内容使用纸白与绿，整稿延续同一方向。这些成稿颜色只属于样稿，不是强制主题。

## 2. 信息架构：三个层级，不堆工具条

- 文档层：名称、模式、保存状态、放映、更多。
- 当前页层：页面导航、新增/复制/删除/排序、页面背景。
- 对象层：统一插入入口；选中后右侧显示相关属性与排列操作。

对象层不得把所有类型的控件同时铺开。普通用户应能直接找到“进入编辑 → 插入 → 图片/文本框/形状/表格”。常驻顶栏不出现 JSON、DOM、adapter、资源池、运行时等工程词。

## 3. 三种模式的完整布局

### 阅读：打开即用

默认首次打开、下载重开和复制到另一台机器打开均进入阅读。56 px 白色顶栏：左侧文件名称，右侧“阅读 / 编辑”分段选择、“放映”和更多。页面导航默认收起，在底部左侧展开。中央一页居中适应空间；底部 36 px 区域包含当前页/总页数、前后页、适应缩放、帮助。阅读不自动进入全屏，也不触发授权弹窗。

不显示对象选择、拖动手柄、虚线、插入与属性面板。保留原有链接、文字复制、媒体播放。未发生编辑时没有保存提示催促。页面之间保持当前位置；没有滚动全文与单页导航混用造成的双重页码。

### 编辑：常用操作可达，属性按需出现

顶栏继续稳定；第二行 46 px：页面栏折叠、撤销、重做、统一“插入”、右侧“页面设置”。撤销/重做图标使用水平回转箭头，分别指向左/右，配 tooltip 与可访问名称，不用抽象曲线。

左侧 204 px 页面栏独立滚动，缩略图和页序号对齐。底部“新建页面”属于栏内固定 footer，**不覆盖滚动内容**。缩放属于工作台底栏，不能侵入页面栏底部。选中对象后右侧出现 264 px 属性面板，关闭按钮明确；未选中时收起，把宽度还给内容。点击“页面设置”可查看背景与页面操作。

选中只出现清晰细描边和控制柄；双击文本进入输入态。属性栏中的编辑不能造成画布失焦后内容丢失。切换对象、页、模式前提交当前输入事务，但不得强制下载或重置历史。

### 放映：产品 UI 完全退出

仅当前页内容，以原有画布比例 contain 到屏幕，必要时黑边。请求浏览器全屏失败时仍能保持同样纯净的窗口内放映。完全移除产品工具条、悬浮菜单、页码 HUD 与鼠标移动召回逻辑；鼠标静止后隐藏指针。浏览器安全提示是浏览器行为，不能承诺消除。

←/→、PageUp/PageDown、空格翻页，B 黑屏，Esc 返回进入放映前的阅读或编辑及当前页。触控横向滑动翻页，避免占用视频拖动、链接和其他内容交互。快捷键说明放在进入放映前可打开的帮助中，不在放映内弹提示。

## 4. 布局、组件与视觉参数

|项目|基准|理由|
|---|---|---|
|画布工作台|#F3F4F6，轻微内容阴影|与白色控制区分层，避免装饰抢内容|
|控件背景|#FFFFFF；hover #F0F1F5|清晰且克制|
|主文字 / 次文字|#20242D / #737A88|稳定层级；可交互文字需实测对比度|
|强调色|#5261D8；浅色底 #EEF0FF|用于主操作、选中与焦点，禁止把所有按钮染色|
|线条|#E7E9EE，1 px|用间距优先，用分隔线辅助|
|字体|系统无衬线；正文 13，标题 14，辅助 11–12 px|不加载外部字体，不将小号低对比字用于关键动作|
|按钮|普通高 32，主按钮 34；图标 18，线宽约 1.65|统一点击与图标语言|
|圆角|控件 6–8，菜单 12，弹窗 16 px|按层级稳定使用|
|间距|4/8/12/16/20/24 px|统一密度；避免每个组件单独随意定值|
|阴影|仅菜单/弹窗与轻量画布阴影|工具条靠边界分区，不做浮动卡片堆叠|
|动态|面板开合约 120–160 ms；尊重 reduced motion|不做持续装饰动画，尺寸变更完成后仅一次 fit|

这些是产品 UI 规格，可以落实为隔离的设计 tokens；不注入作者作品 CSS。必须使用 Shadow DOM/独立文档等现有隔离机制，避免全局 button/input/table 样式污染幻灯片。原型中同文档演示不构成产品隔离实现证据。

## 5. 插入菜单与对象属性

“插入”是一个统一下拉入口，第一层带图标与文字：文本框、形状、图片、表格；已有视频能力可作为次级“媒体”，只有端到端实现可用才出现。禁止无动作占位按钮。图表、公式、评论、联网 AI 面板不属于本轮新增范围。

|对象|插入方式|上下文属性|完整操作要求|
|---|---|---|---|
|文本框|点击后产生可见可输入的新文本，T 快捷键仅编辑且焦点非输入时生效|字体/字号/粗体/颜色/对齐；更细属性折叠|输入、选择、移动/尺寸、删除、复制、历史与保存|
|形状|二级网格：矩形、圆/椭圆、线条；基础形状先形成闭环|填充、边框色/宽、圆角、尺寸|一致选框与操作；线条不能出现误导性的填充控件|
|图片|系统本地选择器；拖入与粘贴可后续复用同一命令，不重复实现|替换、裁切/完整显示、焦点、重置、尺寸|保留比例与原图，裁切非破坏；错误可恢复；按页面布局合理放置|
|表格|行列网格，hover/focus 显示行×列；键盘亦可选择；可用数值方式选择更大表格|单元格文本/填充/边框、行列增删、对齐|明确当前单元格/行/列范围；不以删除末行替代生产版选中行操作|

属性面板分区顺序：对象名称 → 最常用样式 → 尺寸/位置与排列 → 次级操作。首屏优先文本样式/图片裁切等最常用内容，几何区可折叠。支持作者流式布局的对象，不提供虚假的 X/Y 自由拖动；改为布局容器允许的对齐、间距与顺序操作，解释边界。

统一排列：对齐基准默认为当前选择范围；单对象可切到页面/内容区，界面明确基准。多选时只显示共同可操作属性，混合值显示“混合”，不以首个对象值伪装一致。保护状态有锁标识和解锁入口，锁定当前对象不禁用无关新增操作。

对象插入位置不能盲目追加到外层 section 或固定左上角。复用作者内容容器、当前插入点与支持布局，保证可见、可选、可调整。不能通过强制所有对象绝对定位“修好”编辑器。N02/N03 的响应式保真与图片层叠是本设计验收前提。

## 6. 页面操作

缩略图单击导航、拖动排序，提供键盘等效“上移/下移”；右键或页项更多收纳复制、删除、移动。新增在当前页后面，继承适用的背景/布局合同，保留响应式或固定画布，不捕获编辑窗口像素固化。新页内容有可用留白；保留唯一 slide identity。

普通删除支持撤销，不做每次确认弹窗。仅不可恢复操作需要确认。本轮不新增章节管理和复杂母版系统。页面属性明确“当前页”；影响整稿的操作必须单独标注范围，不能静默覆盖全部页面。

## 7. 保存状态：清楚且真实

默认单个 .ppte.html 文件，不建立 HTTP 服务。原型为避免冒充原生授权，只演示真实下载副本；产品接入以下能力分支：

|状态|界面文案与行为|
|---|---|
|只读浏览、未修改|不显示“未保存”焦虑提示；阅读进入编辑无权限门槛|
|编辑后、未关联可写句柄|“修改尚未写入文件”；主操作“保存”，打开小型保存面板选择“关联原文件并保存”（仅受支持时）或“下载更新后的文件”|
|已授权写回且成功|“已保存”+最近时间；继续编辑自动保存，保存按钮/⌘S仍可立即保存|
|正在写入|“正在保存…”；连续修改合并，必须防旧快照覆盖新版本|
|授权失效或写入失败|“尚未保存”+重试/重新授权/下载完整文件；保留全部内存改动，不抹掉错误|
|下载已发起|“已发起下载，原文件未覆盖”；不能显示已自动写回。是否发生下载完成按可获知证据措辞|
|检测到原文件外部变化|提示选择重新读取或下载当前修改，不静默覆盖；保留可恢复内容|

保存入口保持稳定位置；未关联也不能只有含混的“保存副本”按钮。浏览器缓存恢复必须标注“恢复了本机草稿，尚未写入文件”，不是磁盘自动保存。关闭有未写入改动时采用浏览器允许的离开提醒；禁止许诺浏览器退出时一定能保存。

更多菜单：按需 PDF（整稿/当前页范围明确）、下载完整 HTML、快捷键与帮助；只显示可用功能。不默认产生 PDF、多份格式或调试文件。原型“打印当前页 / PDF”特意标明范围，不能当作产品整稿打印实现。

## 8. 细节、反馈与异常

- 菜单：锚定触发器，自动避开边缘；最多两层，形状/表格面板用明确返回。外部点击/Esc关闭，关闭恢复触发器焦点；方向键导航，Tab不困住用户。菜单不滚进画布、不被内容 z-index 盖住。
- 选择：单击选对象，双击文本输入；输入中快捷键优先文本编辑；多选与对象编辑避免手势冲突。拖动支持精细键盘位移，变化纳入同一历史事务。
- 空状态：没有内容时在画布中心显示“从一个重点开始”及插入入口；不把空文档渲染为崩溃；初始一张空页即可。
- 失败：图片无法解码、格式不支持、文件过大、保存失败都显示可操作短句，保留之前对象；不只在控制台打印异常。
- 撤销：无历史时禁用；拖动全过程一个事务，输入适度合并，不能每个 pointermove 都存整稿。新操作清除重做分支。
- 删除/重复：通常可撤销，不叠加无意义确认。重要错误常驻到恢复；轻量成功提示短暂出现，但放映不弹出任何产品 toast。
- 导入大媒体：显示局部进度，可取消，不锁整份稿。延续资源去重与内存要求，不为了原型效果引入新依赖。
- 同一文件、不同角色：作者生成自由 HTML；读者无需 Node、NPM 或 API key；不在离线编辑器伪造自动 AI 选图功能。

## 9. 自适应与可访问性

≥1280：204 px 页面栏、264 px 属性栏，画布居中。1024–1279：页面栏约170、属性约238；保留插入、撤销、放映，不用横向溢出隐藏主操作。820以下：开启属性时先收页面栏；不同时挤出三栏。580以下：默认阅读体验优先，编辑属性采用可关闭底部/侧边抽屉，显示时不冒充画布可完整操作；页面导航抽屉与属性抽屉互斥。44 px触控命中区可通过容器扩大，不能仍用桌面32px按钮宣称触控通过。

所有图标有可访问名称和 tooltip，焦点可见，菜单与模式暴露正确语义/状态。视觉分组不能只靠颜色。关键文字满足正常对比要求；装饰性弱字不承载错误、保存等重要信息。缩放200%、系统大字体、键盘全流程和屏幕阅读器需实测。原型响应式截图不等同于以上全部通过。

## 10. 实现拆分与质量门槛

先从 workspace 中提取模式控制器、文档栏、编辑工具条、页面导航、插入菜单、属性面板、底栏；复用现有 Commands 与保存适配，不增加第二份内容事实源。图标使用一套本地 SVG，资源随 HTML 内嵌，无 CDN。菜单、选中状态与视觉反馈属于 UI 状态，不参与导出内容序列化。

推荐顺序：模式与外壳 → 插入与属性 → 页面/布局组合缺陷 → 保存状态 → 无障碍与适配 → 三模式全旅程验收。每步回交实现提交与对应证据，不把原型复制到成品后就标完成。UI 面板开关不重建全部作者 DOM；缩略图按可见区与变更刷新，继续 S04 性能工作。

必须过的真实旅程：离线直开阅读 → 编辑 → 四类对象各操作 → 撤销重做 → 保存或准确下载 → 关闭并新进程重开 → 纯净放映与退出 → 按需整稿 PDF。覆盖原生 HTML 的 Grid/Flex、流式文本、绝对定位、响应式画布、图片与表格混排，以及12页和长稿。鼠标命中失败不能用 force click 隐藏；DOM内部命令成功不等于 UI成功。

视觉验收：用户确认界面简洁、入口可找到、图标可辨认；逐模式截图+真实操作，不用单一静态截图替代。审美仍需整稿人工反馈；本原型一致背景仅演示一种恰当表达，不变成 Skill 硬规则。

## 11. 原型能力与未实现列表

可体验：默认阅读；页面导航；编辑模式；上下文面板；文本/矩形/椭圆/线条/本地图片/表格插入；基础输入与几何/色彩修改；复制删除、层级、撤销重做；新增/复制/删除页；真实下载含当前内容的原型副本并阅读重开；纯净放映、黑屏与退出。

尚未接入：生产 Commands、原生文件授权与自动保存、任意作者流布局、多选、真实表格选区格式、页面拖动排序、整稿 PDF、系统 IME 完整事务、屏幕阅读器完整语义。示例 art 为展示性 SVG；原型字体只显示系统字体；生产应显示真实可用选择，不能无意义保留单选项下拉。原型在几何控件、选中后再次拖动等细节上是演示简化，按正文规范落地，不应直接当发布候选。
