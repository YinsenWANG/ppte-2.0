## B2 的实现与验证

当前基线已有修复：`content.ts` 的 `safeWebNavigation` 仅放行 a/area 的绝对 http/https 网页 href；`runtime.ts` 在受信任点击时由父运行时用 noopener,noreferrer 打开，当前稿不被导航覆盖，文字编辑时不导航。作者 iframe 仍只有 allow-same-origin，事件属性、ping、危险协议、相对 URL、凭证 URL 和自动外部资源加载继续拒绝，CSP 未放松。本轮核对后保留该实现，没有重复改写策略。

原有三个 B2 测试原样保留所有断言；本轮增加编辑态点击不创建新页、不增加导航请求的断言。原样本在 Chrome headless file:// 上真实鼠标点击 GitHub、保存序列化重开后 Enter 点击官方网站，opener=null、原稿地址保留、合成点击不导航。外部目的地由 Playwright 路由返回本地测试响应，不实际访问网站。历史 F06 拒收复现仍测试历史清洗器，不删除或弱化旧断言。

## 全旅程与证据层次

新增 `tests/u05-delivery.test.ts`，在 U01 原九页单 HTML 副本上连续执行：阅读全部九页 → 编辑封面文字 → 从控件插入本地 PNG → 真实鼠标拖动、角点缩放、裁切 → 撤销并重做（逐字节内容相等断言）→ 点击保存和选择当前文件入口 → 写回同一路径 → 关闭整个 headless 浏览器进程 → 启动新进程重开 → 核对文字、图片几何及完整内容 → 放映全部九页。网络请求和页面异常均必须为空；原始干净成稿必须字节不变。

保存使用显式测试替身实现 `showOpenFilePicker`/文件句柄，读写的是实际磁盘文件；不能证明原生选择器、权限提示和用户目标机写回可用。插图通过 Playwright filechooser 设置本地文件，不是原生 OS 选图对话框证据。放映为真实浏览器自动化，不能充当物理桌面/人工观感验收。

第一次定向运行失败原因：测试将 SVG 送入明确只支持位图的插图控件。改为由浏览器把既有原创概念图栅格化为 PNG 后插入（不是 PDF，也非整页截图）；首次失败日志保留在 verification/targeted-initial.log。没有改产品支持范围或放松断言。定向测试通过后执行完整门禁，结果与计数见 verification/result.json。

`journeys/full-journey.json` 记录各步骤、浏览器版本、写回哈希及时间；screenshots/ 为 headless 实际截图，已查看封面阅读及重开截图。`verification/desktop-probe.json` 记录本轮只读桌面可访问性查询在 8 秒后超时并终止；本会话无可调用桌面工具，未操作原生选择器，不能判断目标机是否授权或操作成功。
