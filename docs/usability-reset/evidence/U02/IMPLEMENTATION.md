# U02 — 图片直接操作重做

用户已拒收“插入图片调整控件非常难用”。本轮实现和新的自动化证据不撤销这一体验结论；U02 保持 reopened，等待目标机和用户重新验收。

## 实现

- 图片普通选中仅有带图标与短标签的“替换图片、裁切、删除对象”，不再出现尺寸、坐标、百分比焦点、旋转、边框或图片批量布局面板。其他既有对象的编辑能力保持。
- 单个插入入口直接选择文件，解码有进度与取消，错误/取消不改变正文、修订或撤销栈。新图在当前作者页面空白中建立局部图片框；不重排整页，也不挤动已有内容。横竖原图比例保留，小图扩大到可选尺寸。
- 拖图片实时预览目标位置，原位置保持作参照。在原图片所属文档捕获指针，位置预览在编辑器层；四角保持比例缩放，9px 可见标记、44px 命中区；小图片向外扩展命中区，避免四角中心互相覆盖。坐标由当前 iframe 与作者页转换，工作区缩放、滚动、窗口尺寸改变后仍使用作者单位。至少保留24作者像素在页面内，避免完全丢失。
- 双击或“裁切”进入独立裁切态，框外原图半透明；拖原图移动主体，拖框角改变范围，滚轮可放大/缩小原图。完成/Enter 提交；取消/Esc 恢复进入前状态。按钮不挤成竖排。普通方向键微调1px，Shift 为10px，Alt 为8px；文本输入、IME、阅读及放映不抢图片快捷键。
- 预览仅在编辑器层和可清理的临时样式中，不把 pointermove 写入正文。完整拖动/缩放/裁切各一条 Commands 事务，保存只能看到已提交内容。撤销/重做先取消预览；替换期间检测原对象是否改变。
- 已有 Grid/Flex/正常流图片首次转换时留下原标签/样式的不可见占位，原选择器 ID 留在占位上，原图的 PPTe identity 随图片框移动；没有重复 DOM ID。占位不保留原图资源。原图与框尺寸/偏移分离，保存 JSON 元数据和原生 HTML/CSS 使用同一模型。替换只改资源并按比例居中，框位置/尺寸不变。
- Commands 的局部恢复保留已识别节点引用与属性顺序，防止图片框事务之后较早插入/布局撤销出现引用失效或快照冲突。删除图片连同图片框和占位一起事务删除。
- 编辑视口强制 fixed 的临时计算结果不作为作者定位事实保存。静态作者页建立局部 relative 基准；已有局部定位页保留作者位置合同。

## 已验证边界

覆盖普通、无旋转/缩放/透视祖先的 Grid、Flex、正常流和绝对定位结构。平移可转换。带旋转/缩放/透视、图片内边距/边框/蒙版的结构在给手柄前报告未适配；静态页面如果存在依赖页外定位基准的绝对定位对象也拒绝适配，避免改变兄弟布局。不宣称任意 HTML 都能自由拖动。响应式稿中图片框采用作者页面坐标，不把整页固化；未证明复杂响应式重排后的所有视觉组合。

原图无重复编码；较大图可操作和资源保真有自动化断言，不代表长稿输入/拖动性能获得用户认可。没有创建新的历史版本；已有文件历史不清除。

## 旧测试迁移与失败追溯

`tests/helpers/legacy-image.ts` 明确只供旧 Commands 兼容性回归：旧宽高/焦点断言改调用保留的 Commands；旧插入布局夹具显式将测试实例的入口绑定至旧 insertImage 方法。生产代码无此开关。旧测试保留全部正文、几何、原字节、保护、历史和保存断言，但这些路径不再算当前 UI 验收。旧文本 Alt+方向键布局断言改为命令调用，因为新合同禁止在文本输入时抢快捷键。原输入框“50”断言转为同一对象的实际50%计算值。详见 TEST-MIGRATION.json。

旧测试中的产品文字仍用于历史定位；F03 旧 resize 输出已改标 `actualPointerResize:false`、`legacyCommandResize:true`，不再伪称鼠标证据。真实直接操作由上表的新测试独立验证，没有给测试装回隐藏产品参数面板，没有 force click，没有新增 skip 或降低断言阈值。

开发中实际发现并修复：首次按下就开属性栏会移动 iframe、让点击落到别处；缩放/滚动探测出现 Chromium 拖拽卡住；最终显式阻止原生 dragstart、保持原图可命中并同文档捕获，等待窗口重排完成后复测通过（跨文档捕获检查未通过，已撤回该尝试）；Esc 取消手势继续冒泡会退出编辑；恢复属性顺序影响连续历史快照；临时 fixed 页面定位不能带入保存。首轮失败日志保留。诊断中的挂起测试仅停止了本任务的测试进程，没有操作用户 Chrome。
